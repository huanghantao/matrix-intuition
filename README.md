# 🚀 理解矩阵：面向 LLM 的直觉之旅（Python 版）

> 这是一套**完全面向数学小白**的手把手教程：从数轴上的一个点出发，用 Python 亲手造出向量、矩阵变换、注意力机制、RoPE 位置编码，直到用 numpy **从零训练一个两层神经网络**。
>
> **主线**：孟岩《理解矩阵》的核心直觉——「矩阵是线性空间里变换的描述；换一组基，同一个变换有不同的矩阵照片」。
>
> **每走一步，都落到 LLM 的真实部件上**：word embedding、Attention、QKV 投影、softmax、RoPE、线性回归、梯度下降、反向传播。
>
> **适合谁：** 数学只有初中水平、但 Python 比较熟的开发者，正在学大语言模型底层却总被矩阵卡住的人。
>
> **承诺：** 每个概念都从 0 讲透，每一行代码、每一条命令都写清楚，**不需要上网搜任何东西**。

## 🤔 这门课和"啃线性代数教材"有什么区别？

教材教你怎么**算**（行列式、逆矩阵、特征值……），却很少告诉你**为什么**。这门课反过来：

- 矩阵乘法规则为什么长得那么怪？→ 因为它是"连续施加两个变换"，顺序不能换是有几何原因的（Week 3）
- 向量为什么既能表示"对象"又能表示"运动"？→ 因为运动是相对的：`Ma = b` 既是"把 a 变换成 b"，也是"在 M 坐标系里量出 a 的东西，在标准坐标系里量出来是 b"（Week 4）
- 为什么 embedding 的相似度用"夹角"而不是距离？→ 点积的几何意义（Week 5）
- Attention 里的 `QK^T` 到底是什么？→ 就是一堆点积，衡量"词与词之间的亲密度"（Week 6）
- RoPE 为什么能把位置信息塞进词向量？→ 位置 = 旋转角度，`q_m·k_n` 只依赖相对位置 `(m-n)`（Week 6）
- 神经网络为什么能"学习"？→ 前向 = 一连串矩阵变换，学习 = 顺着梯度微调这些变换（Week 8）

每周的章节末尾都有「📌 AI 联系」，把你刚建立的数学直觉直接接到 LLM 的真实部件上。学完这门课，Transformer 论文里的矩阵公式不再是天书。

## 📖 怎么用这套教程

本教程就是本仓库，三个目录各司其职：

```
matrix-intuition/（仓库根）
├── learning-guide/   ← 教程正文（你正在看的）
├── matrixlab/        ← 你的战场：函数体是空的（raise NotImplementedError("TODO")），测试已经写好
├── reference/        ← 参考答案：完整实现，测试全绿
└── figures/          ← 所有配图的生图脚本 + 生成好的图片（想改图就改脚本重跑）
```

1. **按顺序读，别跳。** 每周都依赖前面。
2. **边读边动手。** 看到"请这样写代码"，就真的去 `matrixlab/` 里写。
3. **每写完一块就跑测试。** 绿了再往下走。
4. **卡住超过 20 分钟，去看参考答案**（`reference/` 里的同名文件），看懂后**自己重写一遍**。

> 🖼️ 关于图片：所有涉及精确坐标的图都是**脚本生成的 PNG**（在 `figures/` 里），教程直接引用图片，不用会变形的 ASCII 图。想调整任何一张图，改 `figures/gen_*.py` 脚本重新运行即可。
