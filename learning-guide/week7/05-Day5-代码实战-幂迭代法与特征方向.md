# Day 5：代码实战——幂迭代法与特征方向可视化

> 本章你将：
> - 弄懂**幂迭代法**的核心直觉：随便拿一支向量，反复用 A 去"拽"，它就会自动转向（绝对值）最大的特征方向；
> - 学会用**瑞利商** `(v·Av)/(v·v)` 把特征值"读"出来——不需要解任何方程；
> - 实现 `matrixlab/eigen.py` 的 `normalize / rayleigh_quotient / power_iteration`，跑 `pytest tests -k w7_eigen` 到绿；
> - 用定义本身 `A v ≈ λ v` 亲手验收，确认你求出来的确实是特征值和特征向量。

## 5.1 一个问题：不动方程，怎么找"最长主轴"？

昨天我们定义了特征向量 `A v = λ v`，却没给算法。教科书会教你先解 `det(A − λI) = 0` 这个方程——又繁又没直觉。

工程上其实有个漂亮得多的办法，一句话就能讲清楚：

> **随便拿一支向量，反复用 A 去"拽"它，拽着拽着，它就会自动转成（绝对值）最大的那个特征方向。**

这个过程叫**幂迭代法（power iteration）**。下面我们先不写代码，先把"为什么它会转过去"想通——想通了，代码就是 10 行。

---

## 5.2 直觉：反复拽，方向会自己归位

假设 A 有两个特征方向，对应特征值 λ1 = 3（长）和 λ2 = 1.4（短）。现在我随手拿一支向量 v，它一般不会正好落在某个特征方向上，而是"斜跨"在两个方向之间——也就是说，它 = 特征方向 1 上的一截 + 特征方向 2 上的一截（这就是 Week 2 的"线性组合"，任何向量都能拆成两个基方向的组合）。

现在用 A 拽它一次 `A v`：

- 特征方向 1 上的那一截，被拉长 **3 倍**；
- 特征方向 2 上的那一截，只被拉长 **1.4 倍**。

拽完再看：**3 倍的那截涨得猛，1.4 倍的那截涨得慢**，于是一轮下来，v 的朝向就**朝 λ1 方向偏了一点点**。

再拽一次：λ1 那截已经更大，又被乘以 3；λ2 那截更小，还被乘以 1.4。差距进一步拉大。**拽 n 次之后呢？** λ1 方向的分量涨了 3ⁿ 倍，λ2 方向只涨了 1.4ⁿ 倍——指数级碾压。当 n 足够大，λ2 那截相对于 λ1 那截已经小到可以忽略，整支向量**几乎完全指向 λ1 的方向**。

> 📌 **划重点：反复用 A 拽向量，就是让"最大特征方向的分量"在每一轮都以倍数 λ1 碾压其他分量，最终独占鳌头。** 向量会"自动投奔"（绝对值）最大的特征值所对应的方向。这就是幂迭代的全部魔力——**你甚至不需要知道 λ1 是多少、方向在哪，只要机械地拽，答案自己浮现。**

唯一要防的一件事：每拽一次，向量整体还会被拉长（总长度也乘了个约 λ1），很快就大到溢出。所以**每次拽完都要把它缩回长度 1**（方向不变，只调长度）——这就是为什么要写 `normalize`。

---

## 5.3 读出特征值：瑞利商

向量已经指向特征方向了，特征值怎么读出来？

有个聪明的小公式，叫**瑞利商（Rayleigh quotient）**：

```
瑞利商 = (v · Av) / (v · v)
```

为什么它能读出 λ？看：**如果 v 恰好是特征向量**，那么 `A v = λ v`，代入：

```
(v · Av) / (v · v) = (v · (λv)) / (v · v) = λ (v · v) / (v · v) = λ
```

分子分母里的 `(v·v)` 一约，剩下的**恰是 λ**！所以：

- 当 v **还不是**特征向量时，瑞利商给的是 λ1、λ2 之间的某个"加权平均"值；
- 当 v **越来越接近**特征向量时，瑞利商**越来越接近**对应的特征值；
- 当 v **就是**特征向量时，瑞利商**恰好等于** λ。

所以我们只需两步配合：幂迭代负责"把 v 拽到特征方向"，瑞利商负责"在这个方向上读出 λ"。一个找方向，一个读数值，天作之合。

## 5.4 写代码：三个函数

打开 `matrixlab/eigen.py`。三个函数，逐个来。

**`normalize(v)`** —— 把向量缩成长度 1（方向不变）：

```python
def normalize(v: list) -> list:
    n = (sum(x * x for x in v)) ** 0.5
    return [x / n for x in v]
```

回顾 Week 1/5：向量的长度 = 各分量平方和再开平方（n 维勾股）。`n` 先算出这个长度，再把每个分量除以它。结果长度恰好为 1，方向不变。

手算（对应 `test_normalize`）：`normalize([3, 4])` → 长度 = √(9+16) = 5 → `[0.6, 0.8]`。测试正是断言 v[0]≈0.6、v[1]≈0.8。

> ⚠️ **易踩坑：开平方用 `** 0.5`，别写成 `** 2`。** `x ** 0.5` 是开平方（0.5 次方），`x ** 2` 是平方。分母 `sum(x*x for x in v)` 已经是平方和，再对它开 0.5 次方就是长度。

**`rayleigh_quotient(A, v)`** —— 瑞利商 `(v·Av)/(v·v)`：

```python
def rayleigh_quotient(A: list, v: list) -> float:
    n = len(A)
    Av = [sum(A[i][j] * v[j] for j in range(n)) for i in range(n)]
    num = sum(v[i] * Av[i] for i in range(n))
    den = sum(v[i] * v[i] for i in range(n))
    return num / den
```

- `Av = ...`：矩阵乘向量，注意是 `A[i][j] * v[j]` 对 j 求和，得到新向量的第 i 个分量——这就是 Week 3 学的 `matvec`，这里内联写一遍；
- `num = Σ v[i]·Av[i]`：v 和 Av 的**点积**（对应分量相乘再相加，Week 5）；
- `den = Σ v[i]²`：v 和自己的点积 `v·v`；
- 返回 `num / den`。

手算（对应 `test_rayleigh_on_eigenvector`）：`A = [[2,0],[0,3]]`，`v = (0,1)`。先算 `Av = (0, 3)`；`num = 0·0 + 1·3 = 3`；`den = 0·0 + 1·1 = 1`；商 = 3。而 (0,1) 确实是 A 的特征向量、特征值 3，瑞利商恰到好处地读出了它。

**`power_iteration(A, iters=200, tol=1e-13)`** —— 主循环：

```python
def power_iteration(A: list, iters: int = 200, tol: float = 1e-13) -> tuple:
    n = len(A)
    v = [1.0 / n] * n          # 随便一个初始向量
    lam = 0.0
    for _ in range(iters):
        Av = [sum(A[i][j] * v[j] for j in range(n)) for i in range(n)]
        new_v = normalize(Av)  # 拽完缩回长度 1
        lam = rayleigh_quotient(A, new_v)
        if max(abs(new_v[i] - v[i]) for i in range(n)) < tol:
            v = new_v
            break               # 向量不再变化 = 已经指向特征方向
        v = new_v
    return (lam, v)
```

逐句看：

- `v = [1.0/n] * n`：随便给个初始向量（这里用"全是 1/n"，长度约为 1，方向无特殊偏好）；
- 循环里先 `Av`（拽一次），再 `normalize`（缩回长度 1，防溢出），然后用瑞利商 `lam` 读出当前 λ；
- **收敛判断**：`new_v` 和上一次的 `v` 每个分量差都小于 `tol`（比如 1e-13）时，说明向量已经被拽到特征方向、不再变化了，`break` 收工；
- 返回 `(lam, v)`。

> 💡 **你可能会问：如果"绝对值最大"的特征值是负数，幂迭代会怎样？**
>
> 很有味道的问题。特征值是 −4 时，每拽一次向量在特征方向上被乘以 −4，方向**翻个面**（反向），再翻回来，来回翻——但**始终还停在"那根轴上"（正负两个指向）**。测试 `test_power_iteration_negative_eigenvalue` 用的正是 `A = [[-4,0],[0,2]]`，它断言 `abs(lam) ≈ 4`、v 指向 x 轴方向（`abs(v[0]) ≈ 1`）。所以幂迭代求的是"**绝对值最大**"的特征值，负数也能收敛，只是对应向量可能带着一个 sign（正负号）。

## 5.6 小结

- ✅ 幂迭代直觉：**反复用 A 拽向量**，最大特征方向的分量以倍数碾压其他分量，向量自动转向（绝对值）最大特征方向。
- ✅ 每次拽完 `normalize` 缩回长度 1，防止数值溢出。
- ✅ 瑞利商 `(v·Av)/(v·v)`：v 越接近特征向量，商越接近 λ；v 恰为特征向量时商**恰好等于** λ（把 `Av=λv` 代进去就约出来）。
- ✅ `pytest tests -k w7_eigen` → 6 passed，并用 `Av ≈ λv` 亲自验收了定义。
