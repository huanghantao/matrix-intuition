## 🗺️ 一张图看懂本周三件"正事"

```
              ┌─────────────────────────────┐
              │  矩阵 A 到底能干哪些"正事"？   │
              └─────────────────────────────┘
      ┌─────────────────────┬─────────────────────┬─────────────────────┐
      ▼                     ▼                     ▼
 解方程组 Ax = b        最小二乘：拟合            特征值：找主轴
 已知 A 和 b，          点比未知数多，            Ax = λx：作用后
 反推出原来的 x         没有完美解，             方向不变的向量，
 （Day 1、2）           找"误差平方和最小"       λ 就是拉伸倍数
                        的那条直线               （Day 4、5）
                        （Day 3、6）
```

一个矩阵，三种用法：它可以是"一道待解的题"（解方程找输入）、可以是"一把逼近数据的尺子"（最小二乘拟合）、还可以是"一块有自己纹理的木头"（特征向量 = 木纹的方向）。这一周，三样都学会。

---

## ✅ 学完你会得到什么

- 一个**你自己从零写的**高斯消元器：n 元一次方程组，一键解出 `x`，并且自带"选主元"防除零。
- 一个**你自己从零写的**最小二乘拟合器：一堆散乱的 (x, y) 点进去，出来一条"误差平方和最小"的直线——这就是 AI 损失函数的老祖宗。
- 一个**你自己从零写的**幂迭代器：随便给它一个向量，它自己"转"向矩阵最大的特征方向，再用瑞利商读出特征值。
- 对三个 AI 高频词的地基直觉：**线性回归**、**损失函数**、**主成分（特征值）**——它们全都长在这周三件"正事"上。
- 通往 Week 8 大结业的最后一块跳板：从"拟合一条线"到"训练一个网络"，只差一步。
