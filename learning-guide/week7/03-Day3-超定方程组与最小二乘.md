# Day 3：超定方程组与最小二乘——找不到完美解时的"最佳妥协"

> 本章你将：
> - 撞见一种"**方程比未知数多**"的头疼情况——**超定方程组**，它一般没有精确解；
> - 学会诚实的退路：**没有完美解，就找"误差平方和最小"的那一个**，这叫**最小二乘**；
> - 看懂那条神奇的法方程 $(A^T A) x = A^T y$ —— 不需要严格证明，只需看懂一幅"投影"的画；
> - 实现 `matrixlab/lstsq.py` 的 `fit_line / predict / residual_sum`，跑 `pytest tests -k w7_lstsq` 到绿。

---

## 3.1 先撞上那堵墙：点太多，直线穿不过去

昨天我们解的方程组，"方程个数 = 未知数个数"，恰好能解出一个唯一解，两条直线也恰好交于一点。

但现实世界不是这样的。想象你在记录"学习时长和考试成绩"的关系，测了一堆数据：

```
小时数 x :  0    1    2    3
分数   y : 1.0  2.2  2.8  4.1
```

看起来"学得越多分越高"，你猜它大概是一条直线 $y = a \cdot x + b$。问题来了：**这条直线有两个未知数（a、b），却要同时满足 4 个点**——除非这 4 个点本来就严格共线，否则根本不可能。

对每个点写一个方程 $a \cdot x_i + b = y_i$：

```
a·0 + b = 1.0      （点 1）
a·1 + b = 2.2      （点 2）
a·2 + b = 2.8      （点 3）
a·3 + b = 4.1      （点 4）
```

**4 个方程，2 个未知数。** 这种"方程比未知数多"的方程组叫**超定方程组（overdetermined）**，它的常态是：**无解**。就像让一条直线穿过 4 个东倒西歪的点——办不到。

> ⚠️ **易踩坑：别急着说"那就是没答案"。** 现实数据永远带噪声，永远"穿不过去"，但我们不是要一个"完美穿点"的答案，而是要一个"**离所有点都尽量近**"的答案。这个"尽量近"，就是本周的主角——最小二乘。

---

## 3.2 退而求其次：让"误差"最小

既然穿不过所有点，那就换一个目标。先定义"错得有多离谱"：

对某个点 $(x_i, y_i)$，直线 $y = a \cdot x + b$ 在 $x_i$ 处给出预测 $\hat{y}_i = a \cdot x_i + b$，实际值是 $y_i$，两者的**竖直误差**是：

$$
\text{误差}_i = \text{预测} - \text{实际} = (a \cdot x_i + b) - y_i
$$

这个误差在统计里有正式名字：**残差（residual）**，记作 $r_i$。字面意思就是"**残余下来的误差**"——直线把数据里能用 $y = a \cdot x + b$ 解释的部分"吃掉"之后，每个点上仍然**残存、亏欠的那一小截**。残差不是什么新东西，就是刚才公式里那个竖直误差 $(a \cdot x_i + b) - y_i$，只是给它起了个学名；后面说到"残差"，指的都是它（到 3.2 节末尾的图里，它就是那些红色竖线段）。

有的点残差是正的（直线在点上方），有的是负的（在下方）。**如果直接加起来，正的负的会互相抵消**，明明一堆误差，加起来却是 0——骗自己。所以经典做法是把每个残差**平方**，再加起来：

$$
\text{残差平方和 } RSS = \sum r_i^2 = \sum (a \cdot x_i + b - y_i)^2
$$

平方有两个好处：① 正负都变正，不会抵消；② 大幅度惩罚"离得特别远"的点（误差大 1 倍，平方后大 4 倍）。

> 📌 **划重点：最小二乘 = 找 (a, b) 让这个"残差平方和"最小。** "二乘"就是"平方"（误差的二次方），"最小"就是找使这个和最小的参数。它就是"最佳妥协"的数学定义。

看图：

![拟合直线：让所有红色残差线段的平方和最小](../../figures/out/w7d3_fit_line.png)

蓝点是数据，橙色是拟合出的直线，红色竖线段是每个点的**竖直误差——也就是残差 $r_i$**（有的在直线上方，有的在下方；恰好落在直线上的点残差为 0，看不出红线段）。最小二乘找的那条直线，就是让这些红线段的**长度平方加起来最小**的那一条。注意它可能碰巧穿过个别点，但穿不过所有点——它是"整体离所有点最近"的，不是"逐点完美"的。

> 💡 **你可能会问：为什么要"平方"而不是"绝对值"？**
>
> 绝对值也能避免抵消（|误差| 之和）。但平方有个数学上的甜头：它是一个**光滑**的函数（没有尖角），求"什么时候最小"时可以痛快地求导（Week 8 Day 1 教导数）。绝对值在 0 处有个尖角，处理起来麻烦得多。所以历史上大家选了平方，而且一用就再也回不去了——**它后来直接长成了 AI 的损失函数**（Day 6 细说）。

## 3.3 怎么找那个"最小"？法方程（先看懂一幅二维的画）

问题变成：**在所有可能的 (a, b) 里，哪一个让 RSS 最小？**

这里有一个百年老答案，一句话版本：**用投影。** 这句话不解释就是咒语。三维的图不好画也不好想，我们先用一个**二维的小例子**把它看清楚，再原样搬回真实问题。

**缩小例子：把截距 b 先拿掉。** 模型简化成"过原点的直线" $y = a \cdot x$，只剩一个未知数 a。取两个点 (1, 1) 和 (2, 1)：

```
a·1 = 1      （点 1）
a·2 = 1      （点 2）
```

两个方程、一个未知数——照样超定（除非点 2 的 y 恰好是点 1 的 2 倍，这里不是）。它和开头的例子是同一类病，只是小了一号，正好用来画图。

**第一步：换一双眼睛看"方程组"——它在问"y 能不能被配出来"。**
两个方程的左边分别是 $a \cdot 1$ 和 $a \cdot 2$，合起来看，其实是**一个列向量的线性组合**（Week 2 的老朋友）：

$$
\underbrace{\begin{bmatrix} a \cdot 1 \\ a \cdot 2 \end{bmatrix}}_{\text{直线给出的预测向量}}
\;=\; a \cdot \underbrace{\begin{bmatrix} 1 \\ 2 \end{bmatrix}}_{\text{A 的列：两个点的 } x}
$$

配方比例只有一个 a。把 a 从负无穷取到正无穷，能配出来的**全部预测向量**排成**一条过原点的直线**——这就是 A 的**列空间**（A 只有一列，列空间就是这根线）。"$A x = y$ 有没有解"翻译成几何话就一句：**y 落不落在这条线上。** $y = (1, 1)$ 的方向和 (1, 2) 不同，落不上——所以无解。

**第二步：无解时的最佳妥协 = 线上离 y 最近的那个点。**
在线上滑动 a，每个 a 给出一个候选预测；总有一个位置**离 y 最近**——这个最近点就是 **y 在这条线上的投影 $\hat{y}$**（下图绿色箭头），它对应的 a 就是最小二乘的答案。所以"投影直觉"说白了就是：**拟合 = 在列空间里找离 y 最近的点**，仅此而已。

![二维投影：列空间是一条直线，ŷ 是线上离 y 最近的点，残差与直线垂直](../../figures/out/w7d3_projection_2d.png)

图里每个元素都有名字：橙色直线是列空间（A 的列 (1, 2) 张成），蓝色 y 是真实数据，绿色 $\hat{y}$ 是投影，红色残差 $y - \hat{y}$ 与直线**垂直**（图上有直角标记）。灰色那个是"落选者"：取 a = 1 得到预测 (1, 2)，它到 y 的虚线明显更长——**最小二乘挑的 a，就是让这种距离最小的那个**。

**第三步：为什么"最近"的那一点，恰好是"垂直"落下的？**
反过来想最直观：假如残差**斜着**离开直线，那它沿着直线方向就还留有一个"影子"分量——顺着影子在线上挪一点，就能离 y 更近，说明现在还不是最近；只有当它**笔直地立起来、与直线垂直**时，线上才没有任何方向能更近。初中几何也这么说：**垂线段最短。**

**第四步：把"垂直"翻译回代数，法方程就自己冒出来了。**
"残差与列空间垂直" = 它与 A 的列向量**点积为 0**（Week 5）：

$$
A^T \,(y - A\hat{x}) = 0
\qquad\Longrightarrow\qquad
(A^T A)\,\hat{x} = A^T y
$$

在这个小例子里就是一行初中算术：$5a = 3$，解出 $a = 0.6$，预测 $\hat{y} = 0.6 \cdot (1, 2) = (0.6,\ 1.2)$——和图里完全对上。（$A^T$ 是 A 的**转置**，行变列，Week 3 学过 `mat.transpose`；$A^T \,(y - A\hat{x})$ 就是"拿每一列分别和残差做点积"的一次性写法。）右边这条就是**法方程（normal equations）**——它不是天上掉下来的咒语，只是"残差要垂直于列空间"的代数化身。它还把"一大堆超定方程"缩成了"恰好 n 个未知数、且必定有唯一解"的正常方程组——**用昨天的 `gauss.solve_linear` 一解就出**。

**最后，把小例子换回真实问题**：把截距 b 加回来（未知数变两个，A 多一列），点也变多（方程数 = 空间维数）——故事一字不差，只是列空间从"一条线"升级成"一张平面"。三个点就是三维，还能画出来：

![三维版：y 悬在列空间平面外，ŷ 是平面上离它最近的点，残差向量垂直于平面](../../figures/out/w7d3_projection.png)

蓝箭头是真实数据拼成的向量 y（每个坐标是一个点的实测分数），橙色两列张出的浅橙色平面是列空间，红色残差向量 $y - \hat{y}$ 与平面垂直。还记得 3.2 节那张拟合图里的红色竖线段吗？**那些小竖线段正是残差向量的一个个坐标**——两张图是同一件事，只是换了个空间看。四个点以上就得进四维空间了，画不出来，但你已经知道那里面发生着什么。

> 📌 **法方程 = "y 在 A 的列空间上的投影"的代数写法。** 投影点让残差向量（那条垂直的红线）最短，而这个最短，恰好就是"残差平方和最小"。

## 3.4 手算一下 $A^T A$ 长啥样

别被符号吓到，我们把它展开成初中算术。对直线拟合：

- A 有 n 行 2 列，第 i 行是 $[x_i, 1]$；
- $A^T A$ 是 $2\times 2$，$A^T y$ 是 $2\times 1$。

直接给结论（你写代码时就用它，不必每次现推）：

$$
A^T A =
\begin{bmatrix} \sum x_i^2 & \sum x_i \\\\ \sum x_i & n \end{bmatrix}
\qquad
A^T y =
\begin{bmatrix} \sum x_i \cdot y_i \\\\ \sum y_i \end{bmatrix}
$$

未知数 $x = [a;\ b]$。

对照代码看就清楚了：

```python
n = len(xs)
AtA = [[sum(xs[i] * xs[i] for i in range(n)), sum(xs)],
       [sum(xs), float(n)]]
Aty = [sum(xs[i] * ys[i] for i in range(n)), sum(ys)]
```

- `AtA[0][0]` = $\sum x_i^2$（每个 x 的平方和）；
- `AtA[0][1]` = `AtA[1][0]` = $\sum x_i$（x 的和）；
- `AtA[1][1]` = n（1 的个数 = 点个数，写成 `float(n)` 保证是浮点）；
- `Aty[0]` = $\sum x_i \cdot y_i$，`Aty[1]` = $\sum y_i$。

然后 `a, b = gauss.solve_linear(AtA, Aty)`——复用昨天的机器，解出 a、b。

## 3.5 写代码：三个函数

打开 `matrixlab/lstsq.py`，它顶部已经 `from . import gauss`，你可以直接复用昨天的 `solve_linear`。

**`fit_line(xs, ys)`** —— 拟合直线，返回 `(a, b)`：

```python
def fit_line(xs: list, ys: list):
    n = len(xs)
    AtA = [[sum(xs[i] * xs[i] for i in range(n)), sum(xs)],
           [sum(xs), float(n)]]
    Aty = [sum(xs[i] * ys[i] for i in range(n)), sum(ys)]
    a, b = gauss.solve_linear(AtA, Aty)
    return (a, b)
```

就是上一节那条 $(A^T A)x = A^T y$ 的直译：先拼出 $2\times 2$ 的 `AtA` 和 $2\times 1$ 的 `Aty`，交给 `solve_linear` 解，返回斜率 a 和截距 b。

> 💡 **你可能会问：`float(n)` 干嘛？直接写 `n` 不行吗？**
>
> 这道题的数据都是整数，`n` 是 int。但 `solve_linear` 里面要做除法 `s / M[i][i]`，在 Python 3 里 int/int 已经是浮点除，其实没问题；写 `float(n)` 只是**明确示意**"这是浮点矩阵元"，避免将来有人把 int 搬进别的整数运算时踩坑。习惯上数据一进矩阵就统一当浮点，最省心。

**`predict(x, a, b)`** —— 用拟合好的直线做预测：

```python
def predict(x: float, a: float, b: float) -> float:
    return a * x + b
```

一行：$y = a \cdot x + b$。

**`residual_sum(xs, ys, a, b)`** —— 残差平方和（越小越好）：

```python
def residual_sum(xs: list, ys: list, a: float, b: float) -> float:
    return sum((a * x + b - y) ** 2 for x, y in zip(xs, ys))
```

对每个点算残差 $r_i = (a \cdot x + b - y)$，平方，加起来。这就是 3.2 节定义的 RSS。

> ⚠️ **易踩坑：`(a * x + b - y) ** 2` 的括号。** 一定要先 `(a*x + b − y)` 再 `** 2`。如果写成 `a*x + b - y**2`，就变成"预测减去 $y^2$"，完全不是误差平方，测试 `test_residual_zero_on_exact_fit` 会红——它要求严格共线时残差恰为 0。

## 3.7 小结

- ✅ 数据点比未知数多 → **超定方程组**，一般无解（直线穿不过所有点）。
- ✅ 退路：**最小二乘** = 让**竖直误差的平方和（残差平方和 RSS）最小**，是"最佳妥协"的数学定义。
- ✅ 法方程 $(A^T A)x = A^T y$ 的直觉 = **投影**：y 悬在列空间平面外，取平面上离它最近的点；"残差垂直于平面"翻译成代数，法方程就自己冒出来了。
- ✅ 直线拟合的 $A^T A$ 是 $2\times 2$（含 $\sum x^2$、$\sum x$、n 四项），复用 `gauss.solve_linear` 解出 (a, b)。
- ✅ `pytest tests -k w7_lstsq` → 5 passed。

你已经掌握了"数据太多时如何画出那根最合理的直线"。明天换个话题——**矩阵自己长什么样**（特征值与特征向量）；但先记住今天这个"误差平方和最小"，Day 6 会让你看到它就是 AI 损失函数的祖宗。
