## 4.1 今天的战场：只剩四个函数

`matrixlab/coords.py` 一共 6 个函数。Day 3 你已经填了 `determinant_2x2` 和 `inverse_2x2`。今天的重点是中间这两个"坐标转换器"：

```
to_standard(M, v)   # M 尺子里的读数 → 标准尺子的读数
to_basis(M, w)      # 标准尺子的读数 → M 尺子里的读数
```

（另外两个 `similar_photo` / `is_same_transform` 留给 Day 5。）先花一分钟，把它们的数学原型在脑子里钉牢：

| 函数 | 输入 | 输出 | 数学 | 一句话 |
|---|---|---|---|---|
| `to_standard(M, v)` | v = M 尺子读数 | 标准尺子读数 | $M \cdot v$ | 换到标准尺子 |
| `to_basis(M, w)` | w = 标准读数 | M 尺子读数 | $M^{-1} \cdot w$ | 换到 M 尺子 |

还记得 Day 2 那句 $Ma = Ib$ 吗？`to_standard` 的左手边就是 $Ma$（亮出"这是 M 尺子里的读数 a"），右手边 $Ib$ 是标准读数 b——**同一个向量的两副面孔**。`to_basis` 就是把这个方向反过来。

---

## 4.2 先写 `to_standard`：换到标准尺子

它做的事就是一次矩阵乘向量，我们写一个局部的 $2\times2$ 乘（不依赖别的模块，保持 `coords.py` 自给自足）：

```python
def _matvec2(M, v):
    return [M[0][0]*v[0] + M[0][1]*v[1],
            M[1][0]*v[0] + M[1][1]*v[1]]

def to_standard(M, v):
    return _matvec2(M, v)
```

> 💡 **你可能会问：不是有 `mat.matvec` 吗，干嘛自己写个 `_matvec2`？**
>
> 因为 `coords.py` 的设计是**自给自足**、不多嘴依赖别的模块（Week 4 是全年核心，参考答案里也是自己带小工具）。`_` 开头表示"内部工具，别在外面乱调"。你如果乐意，也可以写成 `from .mat import matvec` 再 `matvec(M, v)`——测试只认结果，不认你内部怎么组织。但为了和 Week 4 的"独立"气质一致，推荐照上写。

用 Day 2 的老例子手算验证：`to_standard([[2,0],[0,3]], [1,1])` 应得 `[2,3]`——M 尺子里读数 $(1,1)$，标准尺子里 $(2,3)$。

---

## 4.3 再写 `to_basis`：换回 M 尺子（回程票登场）

反向就简单了——拿逆矩阵去乘。这里 **Day 3 的 `inverse_2x2` 直接派上用场**：

```python
def to_basis(M, w):
    M_inv = inverse_2x2(M)   # 回程票
    return _matvec2(M_inv, w)
```

验证闭环：`to_basis([[2,0],[0,3]], [2,3])` 应得 `[1,1]`——标准读数 $(2,3)$，换回 M 尺子是 $(1,1)$。和上一小节正好是一去一回。

> 📌 **划重点：** 正反向一套口诀——**`to_standard` 用 M 乘（正向），`to_basis` 用 $M^{-1}$ 乘（反向）**。方向反了，乘的东西也对换。这就是"回程票"最直白的落点。

---

## 4.4 Roundtrip：换过去，再换回来，纹丝不动

"坐标转换器"够不够格，最硬的一条验收标准是 **roundtrip（往返无损）**：

```
先换到标准尺子，再换回 M 尺子 → 应该原样还原。
先换到 M 尺子，再换回标准尺子 → 也应该原样还原。
```

写成代码逻辑就是：

```python
w = to_standard(M, v)      # v（M 读数）→ w（标准读数）
v_back = to_basis(M, w)    # w → 换回 M 读数
assert v_back == v         # 应该一模一样（浮点误差内）
```

为什么必然成立？因为 `to_basis` 乘的是 $M^{-1}$，而 `to_standard` 乘的是 $M$，连起来就是 $M^{-1} \cdot (M \cdot v) = (M^{-1} \cdot M) \cdot v = I \cdot v = v$。**逆矩阵的定义，就是保证这一去一回无损耗。**

> ⚠️ **易踩坑：** 往返无损有个大前提——**M 必须可逆**（$\det \neq 0$）。要是 M 把平面压扁了（Day 3 的 $\det = 0$ 情形），`inverse_2x2` 会直接 `raise ValueError`，`to_basis` 连带报错。这不是 bug，是数学在下最后通牒：压扁了的信息，本来就换不回来。

## 4.5 上点难度：斜尺子 $\begin{bmatrix} 1&1 \\\\ 0&1 \end{bmatrix}$

前面碰的都是规规矩矩的"直角伸缩"尺子（对角线矩阵）。真实世界里，坐标轴常常是**歪的**——这正是"非正交基"的滋味。看这把斜尺子：

```
M = [[1, 1],
     [0, 1]]
```

它的两根轴是 $(1,0)$ 和 $(1,1)$：x 轴还好端端朝右，y 轴却**向右上方歪了 $45^\circ$**（把 $e_2$ 剪切到了 $(1,1)$）。这对应 Week 3 的**剪切（shear）**变换——像把一副扑克牌推歪。

用今天写的转换器在这种斜尺子里走一圈：

```
v = [1, 2]                      # 在 M 斜尺子里读数为 (1,2)
w = to_standard(M, v)           # = [1*1 + 1*2, 0*1 + 1*2] = [3, 2]
back = to_basis(M, w)           # 换回来 = [1, 2]  ✓ 无损
```

`to_standard` 的几何含义：在"x 轴朝右、y 轴朝右上"的斜尺子里，坐标为 $(1,2)$ 的点，拿到标准直角尺里一量是 $(3,2)$。你甚至可以想象右图里那两条歪轴的网格——**尺子歪了，读数照样能换，roundtrip 照样无损**。

这正是 `test_basis_roundtrip_skew` 要替你把关的：不管尺子正不正，只要它可逆，换算就闭环。

> 📌 **划重点（收束前三天）：** 一把"尺子"不必非是直角。**任何两根不共线的向量都能当基**，都能让你在"它"和"标准"之间自由换算。矩阵乘法里那个"歪"，在你眼里从此有了确切的几何身份：它只是在描述一套**斜的尺子**。
