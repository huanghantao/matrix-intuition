## 5.1 一头猪、多张照片：变换是"对象"，矩阵只是"描述"

前面四天，我们一直在两套东西之间来回切换：**变换**（把点搬走）和**坐标系**（换尺子读数）。现在把这两件事揉到一起，回答 Week 3 埋下的一个灵魂问题：

> 同一个"旋转 $90^\circ$"这个动作，在**不同的尺子**下描述出来，会得到**不同的矩阵**吗？

答案：会。而且——**它们依然是同一个动作。** 孟岩用一个"俗到家但好用到爆"的比喻把这事说明了，原文如下：

> 比如有一头猪，你打算给它拍照，只要给照相机选定了一个镜头位置，就可以给它拍一张照片。这张照片是这头猪的一个**描述**，但只是片面的描述——换一个镜头位置，能得到另一张照片，也是同一头猪的另一个片面的描述。**所有照片都是这同一头猪的描述，但又都不是这头猪本身。**
>
> 同样：对于一个线性变换，只要你选定一组基，就可以找到一个**矩阵**来描述它。换一组基，就得到不同的矩阵。所有这些矩阵都是**同一个变换**的描述，却又都不是变换本身。

这个"对象 vs 描述"的分寸，是整个 Day 5 的命门：

| 概念 | 是"对象"还是"描述"？ | 类比 |
|---|---|---|
| 线性变换（那个动作） | 对象（本质） | 那头猪本身 |
| 矩阵 | 描述（拍出来的照片） | 某张特定角度的照片 |
| 基（坐标系 / 尺子） | 拍照所选的视角 | 照相机摆的镜头位置 |

> 📌 **划重点：** 变换是那头猪（唯一的），矩阵是给它拍的照片（随镜头而变）。**别把某张照片误认成猪本身。**

---

## 5.2 换镜头，照片怎么变：$A = P^{-1}BP$

现在把"换镜头"翻译成数学。设：

- 有一个变换，在**标准尺子（$I$）**下的矩阵是 **$B$**（比如旋转 $90^\circ$ = $\begin{bmatrix} 0&-1 \\ 1&0 \end{bmatrix}$）；
- 我们换一套新尺子 **$P$**（P 的列 = 新坐标轴，Day 1 的知识）；
- 问：同一个变换，在**$P$ 这面新镜子里**拍出来长什么样？记这张新照片为 **$A$**。

答案是那条贯穿整周、你即将背下来的式子：

> 📌 **$A = P^{-1}BP$**，也即"先到新尺子看 → 干活 → 再回标准说"，包成一步。

它**不是**凭空规定的，三步正好对应"用新尺子描述旧动作"的往返：

1. **$P$**：把一个"新尺子里的读数"换成标准读数（`to_standard(P, v)`，Day 4）；
2. **$B$**：在标准世界里，真刀真枪把这个动作做一遍；
3. **$P^{-1}$**：干完活的结果，再换回新尺子读数（`to_basis(P, w)`）。

连起来 $P^{-1} \cdot B \cdot P$，就是："在 P 尺子里读数为 u 的点，变换后在 P 尺子里的读数"。这正是测试 `test_similarity_means_same_effect` 替你把关的那句话——**老路（三步绕一圈）和新路（直接拿照片 A 乘）结果相同**。

> 💡 **你可能会问：顺序为什么是 $B$ 夹在中间，$P^{-1}$ 在前、$P$ 在后？**
>
> 记一句"**先换进去、再干活、最后换出来**"：最右边 $P$ 是"换进新尺子"，中间 $B$ 是"干活"，最左边 $P^{-1}$ 是"换回新尺子读数"。矩阵作用从右往左读（Week 3 的 A@B 顺序），所以是 $P^{-1}(BP)$。别把 $P$ 和 $P^{-1}$ 的位置记反——那会拍成一张"左右手互换"的错照片。

## 5.3 相似矩阵：同一头猪，拍得更美

当 $A = P^{-1}BP$ 成立（P 可逆）时，我们就说 A 与 B **相似（similar）**。现在"相似"这个词终于有血有肉了——孟岩原话：

> 所谓相似矩阵，就是**同一个线性变换的不同的描述矩阵**。按照这个定义，同一头猪的不同角度的照片，也可以称为"相似照片"。

所以"相似"不是"长得像"，而是**"同源"**：两张照片拍的是**同一头猪**。换个镜头，照片当然变了样，但猪没变。

> 📌 **划重点：换基不换本质，只是拍得更美。** 相似变换（$A = P^{-1}BP$）把一个"丑矩阵"拍成"美矩阵"（更简单、更对称、甚至对角），而**它俩描述的是同一个变换**。工科里那些"把矩阵对角化、化成标准型"，为啥非要加"相似"这个要求？就是为了保证：**化简前后，描述的还是同一个动作。**

一顿操作下来，你手上应该能写出两张函数的完整逻辑（Day 5 的最后两个函数）：

```python
def similar_photo(P, B):
    P_inv = inverse_2x2(P)
    return _matmul2(P_inv, _matmul2(B, P))   # P⁻¹·B·P，注意先算 B·P

def is_same_transform(A, B, P, eps=1e-9):
    A2 = similar_photo(P, B)
    return all(abs(A[i][j] - A2[i][j]) <= eps for i in range(2) for j in range(2))
```

`is_same_transform` 回答的正是 Day 5 开头那句"给我两张照片，我怎么知道拍的是不是同一头猪"：**拿 P 去当场重拍一张（`similar_photo`），再和手里的 A 逐元素比**，误差在 `eps` 内就认。

## 5.4 照进代码：旋转 $90^\circ$，标准照 vs 拉长照

用一个能在测试里跑通的例子收尾。设动作是"旋转 $90^\circ$"：

```
B = rotation_matrix(90) = [[0, -1], [1, 0]]     # 标准尺子下的照片
P = [[2, 0], [0, 1]]                            # 一套把 x 轴拉长 2 倍的新尺子
A = similar_photo(P, B)                          # B 在 P 尺子下的新照片
```

`A` 就是"同一个旋转"在"x 轴被拉长 2 倍的尺子"里拍的照——它不再是漂亮的 $\begin{bmatrix} 0&-1 \\ 1&0 \end{bmatrix}$，而是一个被"拉伸镜"扭曲过的矩阵。但：

```
is_same_transform(A, B, P)        # True：A 确实是 B 在 P 尺子下的照片
is_same_transform(A, B, [[1,0],[0,1]])   # False：换回标准尺子(P=I)，就不同了
```

换 P，照片 A 就换；而 A 始终与 B **相似**——同一头猪，只是镜头不同、美丑不同。（`test_similarity_photo` 就是这几行。）

## 5.5 一句话预告：相似矩阵"共享血型"

最后埋一枚 Week 7 的钩子。既然一堆相似矩阵拍的是同一头猪，那它们之间**必然共享一些"不随镜头变"的东西**——就像同一条血脉的特征。其中最著名的一条：

> 📌 **相似矩阵有相同的特征值。**（特征值 = 矩阵那根"不被旋转的轴"上拉伸了多少倍，Week 7 Day 4 揭晓。）

现在你只需记住这个因果：**因为 $A = P^{-1}BP$ 描述的是同一个变换，所以 $A$ 和 $B$ 的"本质指纹"（特征值）相同。** 换镜头能改照片，改不了猪的血型。

> ⚠️ **易踩坑：** 相似要求 P **可逆**。P 必须是"合格的换镜工具"（两根不共线的轴）。要是 P 奇异（$\det=0$，Day 3），它没法当尺子，`similar_photo` 会在算 `inverse_2x2(P)` 时直接抛错，而不是算出个像模像样的假照片。
