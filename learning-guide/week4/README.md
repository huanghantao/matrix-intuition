## 🗺️ 一张图看懂本周

![一个矩阵，两种读法——变换，还是坐标系](../../figures/out/w4d1_two_readings.png)

上图是本周的题眼。同样是矩阵 `M = [[2,0],[0,3]]`：

- **左边读法**：M 是一个变换，把向量 v=(1,1) 搬到 Mv=(2,3)；
- **右边读法**：M 是一套新尺子——新 x 轴每个刻度是 2、新 y 轴是 3。在新尺子里读数为 (1,1) 的那个点，用标准尺子量出来正是 (2,3)。

**两种说法，指向同一个结果。** 这就是"运动是相对的"：你可以让点动，也可以让尺子动，数学上完全等价。接下来六天，就是把这个题眼一点点拆开、写进代码、接到 AI。

## 📌 写给急着学 LLM 的你

你可能会想：这一周全是"坐标系""尺子""照片"，跟 transformer 有什么关系？关系大了——**每一个 AI 概念，本质都在"换尺子"**：

- **Word embedding**：把一个词写进高维空间，就是给它选一套"语义尺子"换进去（Week 1、2 已经埋下）；
- **QKV 投影**（Week 6）：`X·Wq` 就是把每个词变换进"查询空间"——这是 Week 3 的变换；
- **PCA 降维、LayerNorm**（本周 Day 6）：找一根更顺手的轴、统一一把尺子——这是**换基**的直接应用。

一句话：**变换是"把点搬到哪"，换基是"换把尺子重新读它"。** transformer 里两种动作都有，而且常常混在一起。把这一周吃透，后面六周全是熟面孔。
