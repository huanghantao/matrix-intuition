## 0.1 先来三个"惊鸿一瞥"

在真正开工之前，我想带你去大语言模型（LLM）的源代码里偷看三眼。别怕看不懂——现在**看不懂才是正常的**，这一章的任务只是让你建立一件事：**你接下来要学的矩阵，就是 LLM 的血液**。等 8 周走完，你再回来看这三段，会倒吸一口凉气："原来这么简单。"

### 第一眼：word embedding —— 一张"把词变成数字"的表

几乎所有 LLM 的第一步，都是把"词"变成一个数字列表。下面这段（从 PyTorch 的 `nn.Embedding` 摘出来、稍作简化）干的就这一件事：

```python
embedding = nn.Embedding(num_words, dim=768)   # 5 万个词，每个词 768 个数
x = embedding(word_id)                          # 输入"第 3 号词"，输出一个 768 维向量
```

那 `768` 个数是什么？给"苹果"这个词找的**坐标**——就像"你的家在 3 号楼 2 单元"，差别只是这个"地址"有 768 个数字，而不是 2 个。本周第 5 章你会亲手感受"给一个东西找坐标"这件事有多自然。而存这些坐标用的那个"数表"（5 万行 $\times$ 768 列），学名叫**矩阵**。

### 第二眼：attention 里的 QK^T

Transformer（现在所有主流 LLM 的骨架）里最核心的一行，长这样：

```python
scores = Q @ K.T          # 每个词"想看看"其他每个词，得分 = 一个矩阵乘另一个矩阵的转置
```

`Q` 和 `K` 都是矩阵（分别是"一堆词的查询"和"一堆词的钥匙"），`K.T` 是"把 K 翻个面"，`@` 是矩阵乘法。这一整行算出来的，是"每两个词之间有多相关"——这是 Attention 机制跳动的心脏。**要彻底看懂它，你只需要两样东西：矩阵乘法（Week 3）和点积（Week 5）**。别急，一个一个来。

### 第三眼：一层神经网络

再往下，每层"神经网络"其实就是一个式子：

```python
h = x @ W + b            # 输入 x 乘上权重矩阵 W，再加偏置 b
```

输入是一堆向量（拼成的 `x`），`W` 是一张填满数字的方阵，`b` 是一个"平移量"。乘一下、加一下——这一层就"算完了"。这行代码，就是第 7、8 周里你会**从零手写 & 训练**的那个东西的完整版式。

> 📌 **划重点：** embedding 是"查表拿坐标"，attention 是"矩阵乘矩阵"，一层网络是"矩阵乘向量再平移"。三件大事，**全是矩阵**。这就是这门课存在的理由：矩阵不是线性代数课本里的冷知识，它是 LLM 正在呼吸的肺。

## 0.2 这门课和"啃线性代数教材"有什么区别

教材教你**怎么算**（行列式、逆矩阵、特征值……），却很少告诉你**为什么**、**这跟 AI 有啥关系**。这门课反过来，一路从"生活里的直觉"走到"LLM 的真实部件"：

| 你会一直困惑的问题 | 本课的回答（在哪一周） |
|---|---|
| 向量到底是个啥？为什么 AI 天天说它？ | 有方向、有长度的箭头，用坐标记进电脑（**Week 1**） |
| 为什么要"一堆向量伸缩再相加"？ | 那是"用基础食材调出任意配方"，坐标的本质（**Week 2**） |
| 矩阵乘法规则为什么长得那么怪？ | 因为它是"连续施加两个变换"，顺序不能换是有几何原因的（**Week 3**） |
| embedding 相似度为什么用"夹角"？ | 点积的几何意义 = 方向的契合度（**Week 5**） |
| Attention 里的 `QK^T` 到底是什么？ | 就是一堆点积，衡量"词与词之间的亲密度"（**Week 6**） |
| 神经网络为什么能"学习"？ | 前向 = 一连串变换，学习 = 顺着梯度微调这些变换（**Week 8**） |

## 0.4 怎么用这套教程：三件套

整个仓库就是你学习的地盘，三个目录各司其职：

```
matrix-intuition/（仓库根）
├── learning-guide/   ← 教程正文（你正在看的东西，只读）
├── matrixlab/        ← 你的战场：函数体是空的（raise NotImplementedError("TODO")），测试已写好
├── reference/        ← 参考答案：完整实现，测试全绿
├── tests/            ← 测试（考卷）：已经写好、已经验证过，别改
└── figures/          ← 所有配图（脚本 + 生成好的 PNG）
```

- **learning-guide/**：只读。每章告诉你"今天要写什么、为什么这么写"。
- **matrixlab/**：你唯一要动的地方。每个文件和 `reference/` 里的同名文件一一对应，但函数体被换成了 `raise NotImplementedError("TODO: ...")` 的空壳。本周只动一个文件：`matrixlab/vec2d.py`。
- **reference/**：卡住 20 分钟以上再看。看懂后**合上它，自己重写一遍**——抄一遍和写一遍，吸收效果差十倍。
- **tests/**：测试就是"考卷"，是最好的需求文档。想提前知道"明天考什么"，直接打开读。

### 一句"IMPL 环境变量"到底怎么用

同一份测试，能考两套代码——靠的是 `IMPL` 这个环境变量，它告诉测试"去哪个目录取代码"：

```bash
IMPL=matrixlab pytest tests -k w1    # 默认：考你写的代码（matrixlab/）—— 一开始全红
IMPL=reference pytest tests -k w1    # 考参考答案（reference/）—— 应该全绿
```

不写 `IMPL=xxx` 时，默认就是 `matrixlab`（你的战场）。你随时能用 `IMPL=reference` 跑到终点"偷看一眼标准答案的效果"，再回到 `matrixlab` 里自己实现。第 3 章会带你亲手把这两个命令各跑一遍。

## 0.5 那行"初中数学就够了"，是认真的

你可以翻前面任何一章确认：本课**不会要求你证明任何东西**，只要求你会这几样（初中必备）：

- 数轴、坐标、格点；
- 一元一次 / 二元一次方程（加减消元法）；
- **勾股定理**：$a^2 + b^2 = c^2$。

函数、三角（sin/cos）、微积分——**全都没学过也没关系，本课会在需要的时候现教**（sin/cos 在 Week 3 用"单位圆"讲，微积分用"变化率"讲）。你唯一需要的"数学外语"是读符号，而本课的公式都用标准 LaTeX 排版（网页里 `$...$` 会自动渲染成漂亮的数学式子），你只管读意思，不用管排版。

> 💡 **你可能会问：我 Python 挺熟，但 numpy/matplotlib 没用过，卡得住吗？**
>
> 卡不住，而且这正是第 3 章的全部内容。numpy 你只要记住一个想法：**数表（一维/二维的格子）= 数组**，运算就是"对整张表一起算"；matplotlib 只要知道"给我数据，我画图"。本课需要用到它们的部分每一行都会讲，绝不留"读者自己去查"的空档。
