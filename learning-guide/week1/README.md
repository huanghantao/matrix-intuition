## 🗺️ 一张图看懂本周要造什么

本周就做三件事，一件比一件近 AI：

1. **把位置说清**：一个数不够，就用两个数——这就是"坐标"。（第 1 章）
2. **把箭头造出来**：位移 = 有方向、有长度的箭头，用坐标记进电脑。（第 1、2 章）
3. **揉它、拉它、再把它和"词"对上**：向量加减、数乘是最原始的"运算"；而"把每个词变成一个坐标（向量）"，正是 LLM 认字的起点。（第 4、5 章）

中间藏着一个跳板：**为什么 LLM 里满屏都是矩阵？** 第 0 章揭开这个谜底——因为矩阵是"对一大堆向量一起做变换"的记账方式，而本周你造的，就是那一大堆向量里最普通的一支箭头。

> 凡是带精确刻度、位置、几何形状的图，教程里一律引用脚本生成的 PNG（见第 1、2、5 章的图）；文字里只有"与坐标无关"的示意才用字符画，绝不让错位的字符图把你带沟里。

## ✅ 学完你会得到什么

- 一个**你自己从零写的**二维向量工具箱：造向量、加、减、数乘、取反、算长度、求两点间位移，全部通过 `pytest tests -k w1`。
- 对"向量"这个 AI 世界里最高频名词的直觉：它是**有方向、有长度的箭头**，用**坐标**记进电脑里——而这个坐标，正是 Word Embedding 的雏形。
- 第一张通往 LLM 的地图：为什么"把词变成向量"是让机器"理解"语言的第一步。
- 一个被反复验证的信念：**这些只需要初中数学**，你早就会了，缺的只是把它们和代码、和"AI"三个字接上。
