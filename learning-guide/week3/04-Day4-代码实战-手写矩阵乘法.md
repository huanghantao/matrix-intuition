## 4.2 matmul：三重循环逐行讲解

先看参考答案的完整实现（`reference/mat.py`）：

```python
def matmul(A, B):
    """矩阵乘矩阵：结果第 i 行第 j 列 = A 的第 i 行与 B 的第 j 列的点积。"""
    rows = len(A)
    cols = len(B[0])
    inner = len(B)
    result = [[0.0] * cols for _ in range(rows)]
    for i in range(rows):
        for j in range(cols):
            s = 0.0
            for k in range(inner):
                s += A[i][k] * B[k][j]
            result[i][j] = s
    return result
```

它看起来有三层循环，其实每层都对应一个非常具体的问题。我们拆开看。

**第 1 行到第 3 行：摸清三个"长度"。**

- `rows = len(A)`：A 有几行，结果就有几行。（每个输出分量来自 A 的一行）
- `cols = len(B[0])`：B 有几列，结果就有几列。（B 的每一列都要被 A 变换一次）
- `inner = len(B)`：A 每行要和 B 每列"相乘相加"，中间要数过多少个元素——这个"中间维度"必须相等，即 **A 的列数 = B 的行数**。

Day 3 讲"行$\times$列点积"时说过：C 的第 i 行第 j 列 = A 第 i 行与 B 第 j 列对应相乘相加。这个"点积"里要累加的元素个数，就是 `inner`。

**第 4 行：造一个全是 0 的结果矩阵。**

```python
result = [[0.0] * cols for _ in range(rows)]
```

外层的 `for _ in range(rows)` 造出 rows 行；每行 `[0.0] * cols` 造出 cols 个 0。得到一个 rows 行 $\times$ cols 列的"空矩阵"，等会儿往里面一格一格填数。

**第 5-6 行：两层循环，遍历结果的每一个格子 (i, j)。**

```python
for i in range(rows):     # i 是"第几行"
    for j in range(cols): # j 是"第几列"
```

`i` 从 0 到 rows-1（结果的行号），`j` 从 0 到 cols-1（结果的列号）。每一对 (i, j) 决定结果里的**一个格子**，我们要算它的值。

**第 7-9 行：最内层循环，算"点积"——这就是那个格子的值。**

```python
s = 0.0
for k in range(inner):
    s += A[i][k] * B[k][j]
result[i][j] = s
```

`k` 是一个"滑动游标"，从 0 走到底，每一步取 `A[i][k]`（A 第 i 行的第 k 个）和 `B[k][j]`（B 第 j 列的第 k 个）相乘，累加到 s 里。走完，s 就是 A 第 i 行与 B 第 j 列的**点积**，把它放进结果格子 `result[i][j]`。

> 📌 **划重点：三重循环三个字母各司其职——**
> - `i` 管"结果的第几行"（来自 A 的行）；
> - `j` 管"结果的第几列"（来自 B 的列）；
> - `k` 管"点积里累加走到哪一步"（中间维度）。
>
> 想清楚这三个字母，三重循环就不神秘了。

**完整流程一句话**：对结果的每个格子 (i, j)，让 k 从 0 滚到底，累加 `A[i][k]*B[k][j]`。

> 📌 **划重点（温故知新）：** 再看看你写的循环结构——最外层 `i` 转一圈，产出结果的**一整行**，用的原料是 **A 的一行 + B 的全部**。这正是 Day 3 §3.3b 那把"按行切"的刀：**你的 `matmul` 本来就是按行切的**，中间两层循环合起来，干的就是一次"行向量 $\times$ 矩阵"。行视角不是什么新运算，它一直住在你的循环里。

## 4.3 手算跟一遍三重循环

拿 A=`[[1,2],[3,4]]`、B=`[[5,6],[7,8]]` 跟一遍，体会三层循环怎么运转。这里 rows=2、cols=2、inner=2。

- 结果格子 (i=0, j=0)：s = A[0][0]*B[0][0] + A[0][1]*B[1][0] = $1\cdot5 + 2\cdot7$ = **5 + 14 = 19**
- 结果格子 (i=0, j=1)：s = A[0][0]*B[0][1] + A[0][1]*B[1][1] = $1\cdot6 + 2\cdot8$ = **6 + 16 = 22**
- 结果格子 (i=1, j=0)：s = A[1][0]*B[0][0] + A[1][1]*B[1][0] = $3\cdot5 + 4\cdot7$ = **15 + 28 = 43**
- 结果格子 (i=1, j=1)：s = A[1][0]*B[0][1] + A[1][1]*B[1][1] = $3\cdot6 + 4\cdot8$ = **18 + 32 = 50**

所以 $A@B$ = `[[19,22],[43,50]]`。你可以用 Python 或 numpy 验证：`np.array([[1,2],[3,4]]) @ np.array([[5,6],[7,8]])` 得到的就是它。

> 💡 **你可能会问：`i`、`j` 倒过来遍历行不行？**
>
> 完全行。`i` 管行、`j` 管列，只是你决定"先填完哪一行"的遍历顺序，不影响结果。数学上 `result[i][j]` 只由 i、j 唯一确定，跟你先算哪个格子无关。写循环时保持 i 在外、j 在内只是习惯，便于"一行一行"地填。

## 4.4 transpose：行列互换

转置是最简单的操作之一：**行变列、列变行**。一个 $m\times n$ 矩阵转置后变成 $n\times m$。

$$
\begin{bmatrix} 1 & 2 \\\\ 3 & 4 \end{bmatrix}
\quad \xrightarrow{\text{转置}} \quad
\begin{bmatrix} 1 & 3 \\\\ 2 & 4 \end{bmatrix}
$$

原来的第 1 行变成第 1 列，第 2 行变成第 2 列。看参考答案：

```python
def transpose(M):
    rows = len(M)
    cols = len(M[0])
    return [[M[i][j] for i in range(rows)] for j in range(cols)]
```

拆读：外层 `for j in range(cols)` 决定转置后有 cols 行（等于原矩阵的列数）；内层 `for i in range(rows)` 是"取原来的第 j 列"——把这一列的 rows 个数依次拿出来，拼成转置后的第 j 行。

一句话：**转置后第 j 行 = 原来第 j 列。**

> 💡 **你可能会问：转置有什么几何意义？**
>
> 本周它只作为"纯操作"出现（测试要求实现它）。它的深层意义留到 Week 5：转置和点积、和"注意力的 $QK^T$"关系极深——那时你会看到 $Q\cdot K^T$（K 的转置）正是"一堆词两两之间的点积"。现在先掌握"行列互换"这个机械操作即可。

## 4.5 identity 与 apply_to_points

**identity（单位矩阵）**：Day 3 见过，主对角线全是 1、其余全 0。

```python
def identity(n):
    return [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]
```

拆读：外层 `i` 是行号，内层 `j` 是列号；只有当 `i == j`（处在主对角线上）才填 1，否则填 0。`i == j` 正好抓住"对角线"这个位置。

**apply_to_points（点列变换）**：给一堆点，逐个变换，返回变换后的点列。这是"批量"的雏形，也是画图脚本天天用的工具。

```python
def apply_to_points(M, points):
    return [matvec(M, p) for p in points]
```

一行列表推导式：对 `points` 里的每个点 p，都算一次 `matvec(M, p)`。之所以有用：Week 3 开头那张"房子变形"的图，本质就是把房子的 5 个顶点交给 `apply_to_points`，再连起来。
