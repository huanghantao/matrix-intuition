# 🚀 Week 3：矩阵 = 变换——空间的运动

> **适合谁：** 学完了 Week 1（向量、坐标、箭头）和 Week 2（线性组合、基、换尺子），Python 熟练，但**没碰过矩阵、没学过 sin/cos** 的读者。
>
> **本周定位：** 这是**整门课的地基**。前两周我们把"向量 = 位置""基 = 尺子"的直觉打牢了，这一周我们要迈出最关键的一步：**把矩阵看成一个动作、一次空间的运动**。以后的 attention、QKV、RoPE、神经网络前向传播，全都建立在这一周的直觉上。
>
> **承诺：** 不要求任何高等数学。sin/cos 我们从零教（单位圆定义，初中就能懂）。每个概念都走"类比 → 直觉 → 定义 → 代码 → 验证"五步。**不需要上网搜任何东西。**

---

## 📖 怎么用本周教程

1. **按顺序读，别跳。** Day 1 的旋转矩阵是 Day 6 RoPE 的地基，Day 2 的矩阵乘向量是 Day 3 矩阵乘法的地基。
2. **边读边动手。** 看到"请这样写代码"，就真的去 `matrixlab/mat.py` 里写。
3. **每写完一块就跑测试。** 绿了再往下走。
4. **卡住超过 20 分钟，去看参考答案**（`reference/mat.py`），看懂后**自己重写一遍**。

## 🗺️ 一张图看懂本周

![三个开胃变换：同一个多边形在拉伸、旋转、剪切下的样子](../../figures/out/w3d1_transforms.png)

> 一个图形（灰色）交给一个矩阵，矩阵就把它"搬"到新位置（蓝色）。
> **拉伸**改变大小、**旋转**改变朝向、**剪切**把它推歪——但它们都是同一个套路：
> **矩阵 = 一次变换，矩阵乘向量 = 把这个向量搬过去。**
> 本周剩下的五章，全是在把这个直觉往深、往代码、往 LLM 里铺。

## ✅ 学完你会得到什么

- 一个**你自己从零写的矩阵工具箱**（`matrixlab/mat.py`）：能算矩阵乘向量、矩阵乘矩阵、转置、单位矩阵、点列变换。
- 对"矩阵是运动的描述"（孟岩《理解矩阵》原话）**透彻、可脱稿讲解**的理解。
- **为什么矩阵乘法的"行$\times$列"规则是必然的**——不是数学家拍脑袋规定，而是"连续施加两个变换"逼迫出来的结果；以及为什么 $A@B \neq B@A$（穿袜子穿鞋类比）。
- 一个通往 Week 4（矩阵 = 坐标系，变换的相对性）、Week 5（点积 = 相似度）、Week 6（attention 与 RoPE）的**地基**。

## 🧭 常用命令速查

```bash
# 进入项目根目录（写作/跑测试都在这里）
cd matrix-intuition

# 跑本周全部测试（检验你写的代码）
pytest tests -k w3

# 用参考答案看最终效果（见证终点）
IMPL=reference pytest tests -k w3

# 只看某一条测试的详细信息
pytest tests/test_w3_mat.py -vv
```

> `matrixlab/` 是**你的战场**（函数体里是 `raise NotImplementedError`，等你填）；
> `reference/` 是**参考答案**（已定稿、已通过全部测试）；
> `tests/` 是**裁判**（8 条测试，`reference` 全绿）。
> 卡住时，去看 `reference/mat.py` 里的同名函数。
