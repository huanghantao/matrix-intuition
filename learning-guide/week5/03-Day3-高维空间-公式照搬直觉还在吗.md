# Day 3：高维空间——公式照搬，直觉还在吗

> 本章你将：
> - 亲眼看到：**3 维、n 维的点积/长度/夹角公式，就是 2 维那句口诀的机械重复**，一行都不改；
> - 掌握一个绝招：**高维画不出来没关系，靠"低维投影"来想**——任何一对高维向量，都能"剪"出它俩所在的平面；
> - 确认：点积在 768 维照样是"亲密度"，不需要你证明任何东西；
> - 为第 4 天直接用 768 维 embedding 算相似度扫清心理障碍。

---

## 3.1 一个心结：二维的东西，凭什么管三维以上的事？

前两天的图全画在**平面上**（2 维）：两根箭头 x 和 y 坐标各一个。可你早就知道，真实世界的 embedding 是 **768 维、1024 维**的——一个词对应一串几百上千个数。那么问题来了：

> 我脑子里关于"点积 = 影子 $\times$ 长度""夹角越小越亲"的画面，只活在二维平面里。**到了 768 维，这些公式和直觉还成立吗？**

这是个再好不过的问题，也是很多人卡在 LLM 底层数学前的最后一堵墙。今天这章，专门来拆这堵墙。先给结论，安你的心：

> 📌 **划重点：** 公式不需要改。2 维、3 维、768 维，点积、长度、夹角长的是**同一副样子**——因为高维不过是"几个维度各管各的，再汇总"。真正会变的只有一件事：你**画不出来**了。直觉靠"投影"来借，不用新造。

---

## 3.2 先上 3 维：把公式"堆"一层

别急着跳 768 维，先到 3 维。3 维空间就是一个普通房间：前后、左右、上下三个方向，一个点用 `(x, y, z)` 三个数描述。

**点积**在 3 维长这样：

$$u \cdot v = u_1 v_1 + u_2 v_2 + u_3 v_3$$

比 2 维多了一对 `u3×v3`，仅此而已。手算一个：`u = (1, 2, 2)`，`v = (0, 3, 4)`：

$$u \cdot v = 1\times0 + 2\times3 + 2\times4 = 0 + 6 + 8 = 14$$

**长度**跟着一起长，多一个坐标就多一个平方：

$$|u| = \sqrt{u_1^2 + u_2^2 + u_3^2}$$

`|(1, 2, 2)| = √(1 + 4 + 4) = 3`（上一天算过）。

**夹角公式纹丝不动**：

$$\cos\theta = \frac{u \cdot v}{|u|\ |v|}$$

> 💡 **你可能会问：3 维的"长度=勾股定理"我还能勉强想象（拿两条边先勾一次，再和第三条边勾一次），那 4 维呢？**
>
> 你没法"看见" 4 维，但**公式允许你不看**。长度公式从来不问你"这是几维的房间"，它只做一件事：把每个坐标的平方加总、开根号。3 维多一步，4 维再多一步……它不在乎你脑补不脑补得出来。这就是那句话——**别用眼睛，用公式。**

---

## 3.3 n 维：同一句口诀的机械重复

现在把"3"换成"n"。假设一个向量有 n 个坐标：`u = (u1, u2, …, un)`。那么：

$$\begin{aligned}
\text{点积}\quad &u \cdot v = \sum_i u[i] \times v[i] \quad (i\text{ 从 }1\text{ 加到 }n) \\\\
\text{长度}\quad &|u| = \sqrt{\sum_i u[i]^2} \\\\
\text{夹角}\quad &\cos\theta = \frac{u \cdot v}{|u| \cdot |v|}
\end{aligned}$$

看清了吗？三个公式里**连一个"2"或"3"的影子都没有**，n 是多少都无所谓。你昨天在 `matrixlab/proj.py` 里写的代码，用的正是这个形式：

```python
def dot(u, v):
    return sum(a * b for a, b in zip(u, v))  # zip 自动配到多长算多长
```

`zip` 不关心向量是 2 个还是 768 个坐标——它配到哪算哪。**所以你昨天写的 `dot` / `norm` / `angle_deg`，早就已经是"768 维可用"的完整实现了**，一行都不用改。这就是"公式照搬"最实在的证据：代码层面，维度根本不设限。

---

## 3.4 直觉怎么办：靠"投影"降维去想

公式的事解决了，但"直觉"的事还没解决——数学能算，可我们这种二维生物**脑补不出 768 维是啥样**啊。答案藏在一个大招里：

> 任何两个向量 u、v，**不管它们活在 768 维还是 1000 维，它们俩只"摊开"在一个二维平面里**。

想象你站在一间屋子里，手里捏着两根长长的杆子（假设它们有很多"维度"）。你没能力同时看见所有维度，但你可以做一件事：**找到这两根杆子共同撑开的那张"平面"（一张 2D 纸），只盯着这张纸看**。在这张纸上，两根杆子又变成了两根普普通通的二维箭头——夹角、影子、亲密度，全都原封不动地呈现出来。

数学里这件事叫"**高维的直觉靠低维投影来理解**"：你把注意力从 768 维里抽出来，只投到"u 和 v 所在的平面"这个 2 维切片上。这一投，768 维的图像就降成了你熟悉的 2 维图像：

```
768 维空间里的两根向量
        │
        │  “剪”出它俩张成的平面（一个 2 维切片）
        ▼
一张纸上的两根箭头  →  夹角、影子、点积 照旧
```

> 📌 **划重点：** 高维画不了，但**"任何一对向量只占一个二维平面"**。所以所有二维直觉都有效——你只是把"看图"换成了"在心里剪一张切片"。维度高低不影响直觉，只影响你**画图的张数**（768 维里到底能剪出多少对平面，那数大到天文数字，但每对都只是一张 2D 纸）。

## 3.5 点积在 768 维照样是"亲密度"：不证，但信得踏实

有人到这儿会较真："你说了半天'公式照搬、直觉靠投影'，倒是**证明**一下 768 维的点积还等于 `|u||v|cosθ` 啊？"

我们的回答很干脆：**本课程不要求、也不需要你证明任何东西**（这是这门课从头到尾的铁律）。你只需建立"信得踏实"的直觉，它分两层：

1. **公式本来就只在定义"对应相乘相加"**，维度没参与决策——所以它天生就是 n 维的样子。
2. **几何读法（影子 $\times$ 长度 / 夹角）是"低维切片里"发生的事**。既然每一对向量都能剪成一张二维纸、在纸上演绎出影子与夹角，那"点积 = 亲密度"在 768 维就**自动成立**——它是 768 个坐标"各管各、再汇总"的必然结果。

> 💡 **你可能会问：那 768 维里还能"垂直"吗？能"正交"吗？点积为 0 还代表"垂直"吗？**
>
> 能，而且同样成立。768 维里两根向量点积为 0，叫做**正交**，它对应的仍然是"剪出来的那张纸上，两根箭头互相垂直、影子缩成一个点"。名称、判定、几何意义，和 2 维一字不差。你以后看 paper 里的"正交基""$QK^{\mathsf{T}}$ 里某些分数接近 0"（即某个 query 和某个 key 近乎垂直、互不理睬），就都是这个"点积为 0"在起作用。

## 3.6 顺带说一句：高维的"直觉"也有人会搞错的地方

既然聊到高维，顺手给你打两支预防针，都是将来读 LLM 材料时容易踩的：

**① 别拿"距离长短"当成"语义远近"。** 在 768 维里，两个词的 embedding 可能"坐标差很大"（欧氏距离远），但方向几乎一致——它们照样是近义词。这正是第 4、5 天要讲的"余弦相似度之于距离"的核心对比。方向（夹角）才是语义，长度常常是噪声。

**② 维度高不等于"信息一定多"。** 768 是"坐标刻度的数量"，不是"玄妙程度"。每个维度就是一个"语义读音"（Week 2 Day 6 讲过"语义配方"的直觉），点积只是把这些读音一对一对唱和再求和。别被大数字吓住——**768 维的点积，算起来就是 768 次乘法和 767 次加法**，跟算 2 维点积一样朴素。

---

## 3.7 本章小结

- ✅ 3 维、n 维公式 = 2 维口诀的机械重复：点积 `Σ u[i]v[i]`、长度 `√(Σ u[i]²)`、夹角 `cosθ = u·v/(|u||v|)`，一个字符都不必改。
- ✅ 代码早就支持 n 维：`zip(u, v)` 配到多长算多长，你第 1 天写的 `dot` 直接通吃 768 维。
- ✅ 直觉靠**低维投影**：任何一对向量只张成一个二维平面，剪出那张纸，夹角/影子/亲密度全回来了。
- ✅ 不证，但信得踏实：点积在 768 维照样是"亲密度"，正交（点积为 0）照样是"垂直"。
