# Day 5：代码实战——换基器与"配方"求解

> 本章你将：

> - 学会处理一个坑：第一个式子没有 $x$ 时，要先**交换两个式子**（选主元）；

## 5.1 我们要造的东西

打开战场 `matrixlab/solve2.py`，里面两个空函数，合起来就是一个"**换基器**"：

```python
def solve_2x2(a, b, c, d, e, f):
    """解方程组 a*x + b*y = e；c*x + d*y = f，返回 (x, y)。"""

def coordinates_in_basis(b1, b2, v):
    """在基 (b1, b2) 下表示向量 v，返回系数 (s, t)，满足 v = s*b1 + t*b2。"""
```

`coordinates_in_basis` 是面向用户的接口：给它两支尺子 $b_1$、$b_2$ 和一个向量 $v$，它吐出读数 $(s, t)$。底层它调用的就是 `solve_2x2`——把 $s\cdot b_1 + t\cdot b_2 = v$ 展开成两个方程再解。

先说清 `solve_2x2` 的参数和方程写的对应关系，这一步错了后面全白搭：

$$
\begin{aligned}
a\,x + b\,y &= e \qquad &&\text{第一个方程，}x\text{ 系数 }a\text{，}y\text{ 系数 }b\text{，常数 }e \\\\
c\,x + d\,y &= f \qquad &&\text{第二个方程，}x\text{ 系数 }c\text{，}y\text{ 系数 }d\text{，常数 }f
\end{aligned}
$$

对照 Day 4 的例子 $2s - t = 4$、$s + t = 3$（把未知数 $s$、$t$ 换成通用名 $x$、$y$）：

```
a=2, b=-1, e=4
c=1, d=1,  f=3
```

---

## 5.2 复习消元公式（Day 4 的机械版）

Day 4 我们"看着好消的未知数下手"消了 $t$。但代码不能"看着来"，它要一股脑按固定套路走。套路就是：**把 $x$ 的系数凑成 $a\cdot c$，让两个式子的 $x$ 系数一模一样，再相减消掉 $x$。**

先把 Day 4 的代换关系摆出来（未知数统一叫 $x$、$y$，别管它们几何上叫 $s$、$t$）：

第一式两端乘 $c$：

$$ a\cdot c\cdot x + b\cdot c\cdot y = e\cdot c $$

第二式两端乘 $a$：

$$ a\cdot c\cdot x + a\cdot d\cdot y = a\cdot f $$

现在两个式子的 $x$ 系数都是 $a\cdot c$，相减（第一式 - 第二式）消掉 $x$：

$$ (b\cdot c - a\cdot d)\cdot y = e\cdot c - a\cdot f $$

于是解出 $y$：

$$ y = \frac{a\cdot f - e\cdot c}{a\cdot d - b\cdot c} $$

（注意：分子用了 $a\cdot f - e\cdot c$，分母 $a\cdot d - b\cdot c$，两者只是把上一行的减号整理了一下，符号是配好的。）

出 $y$ 之后，代回第一式求 $x$：

$$ x = \frac{e - b\cdot y}{a} $$

这就是 Day 4 那四步的"公式版"。$a\cdot d - b\cdot c$ 这个分母马上会反复出现，它还有个把门的作用，下面 5.4 说。

---

## 5.3 第一个坑：第一个式子没有 x

如果 $a$ 碰巧是 0，上面 $x = \frac{e - b\cdot y}{a}$ 会除以 0 崩掉。先看一个例子：

$$
\begin{aligned}
0x + 2y &= 4 \qquad &\leftarrow\ (a = 0) \\\\
3x + y &= 5 \qquad &
\end{aligned}
$$

第一个式子根本不含 $x$，没法拿它当"主元"去消别人。怎么办？**把两个式子交换一下**：

$$
\begin{aligned}
3x + y &= 5 \\\\
0x + 2y &= 4
\end{aligned}
$$

现在第一个式子有 $x$ 了，主元就位，公式照常运转。这个"交换式子、选出一个不为 0 的系数当主元"的动作，就是**选主元（pivoting）**。它解决的正是 Day 4 那节"挑好消的未知数下手"——代码里我们规定"总让含有 $x$ 的式子排在前面"。

体现在代码里：

```python
if abs(a) < eps:
    # 第一个式子没有 x，交换两个式子
    a, b, c, d = c, d, a, b
    e, f = f, e
```

> ⚠️ **易踩坑：交换两个式子时，$x$、$y$ 系数和常数要**成对**一起换。** 别只换 $a$ 和 $c$ 却忘了 $e$ 和 $f$——那样方程就变成另一道题了。

---

## 5.4 第二个坑：两直线平行（或重合）

分母 $a\cdot d - b\cdot c$ 有个专门的用途：它叫这个方程组的**行列式（determinant）**，几何上等于"两把尺子张成的平行四边形面积"。

- 分母不为 $0$ → 两支尺子不共线，有唯一交点 → 正常解出；
- 分母为 $0$ → 两支尺子共线（平行或重合），没有唯一读数。

Day 4 末尾那张表说的"无解 / 无穷多解"，在代码里统一处理成一句话：**抛 `ValueError`，告诉你"没有唯一解"**。

```python
det = a * d - b * c
if abs(det) < eps:
    raise ValueError("没有唯一解：两直线平行或重合")
```

（`eps = 1e-12` 是判断"是不是 0"用的极小阈值，浮点数算出来不会恰好是 0，用 $|x| < 10^{-12}$ 兜底。）

还有另一种"没有唯一解"：两个式子**都没有 $x$**（$a$ 和 $c$ 都是 0）。这种情况 $x$ 可以随便取、$y$ 也未必能定死，同样抛错。检查顺序是：先查"两个式子都没有 $x$"，再查"第一个没有 $x$ 就交换"，最后查行列式。

完整的判断链条，正是 `reference/solve2.py` 里注释逐条写的那段。动手前建议先把那几条注释读一遍，理解每句"没有唯一解"对应 Day 4 的哪种病态。

## 5.5 组装成换基器：coordinates_in_basis

`coordinates_in_basis(b1, b2, v)` 求读数 $(s, t)$，满足：

$$ s\cdot b_1 + t\cdot b_2 = v $$

把它拆成两个坐标方程（未知数是 $s$、$t$）：

$$
\begin{aligned}
s\cdot b_1[0] + t\cdot b_2[0] &= v[0] \qquad &\leftarrow\ x \text{ 方向（第一坐标）} \\\\
s\cdot b_1[1] + t\cdot b_2[1] &= v[1] \qquad &\leftarrow\ y \text{ 方向（第二坐标）}
\end{aligned}
$$

对照 `solve_2x2(a, b, c, d, e, f)` 的参数位：

```
a = b1[0], b = b2[0], e = v[0]
c = b1[1], d = b2[1], f = v[1]
```

所以这个函数几乎就是一行**转接**：

```python
def coordinates_in_basis(b1, b2, v):
    return solve_2x2(b1[0], b2[0], b1[1], b2[1], v[0], v[1])
```

> 💡 **你可能会问：为什么 $x$ 方向的方程里，$a$ 取的是 $b_1$ 的第一个坐标、而不是 $x$ 系数？** 因为未知数不是坐标，是**系数 $s$、$t$**。$s\cdot b_1[0]$ 里 $b_1[0]$ 是 $s$ 前面的系数，所以它填到 $a$ 的位置。把"谁当未知数"想清楚，就不会填错位。

## 5.6 验证：换过去，再换回来（roundtrip）

写完后，最有说服力的验收不是盯着某个测试，而是**绕一圈**：换基 → 换回来 → 看是不是还原。

思路：拿到读数 $(s, t)$ 后，用 Day 1 的 `lincomb` 把基向量重新组合起来，理应精确回到原向量 $v$：

```bash
IMPL=matrixlab python -c "
from matrixlab.solve2 import coordinates_in_basis
from matrixlab.combo import lincomb
b1, b2 = [2, 1], [-1, 3]
v = [5, -4]
s, t = coordinates_in_basis(b1, b2, v)
print('读数:', (s, t))
back = lincomb([s, t], [b1, b2])
print('还原:', back)
"
```

如果 `back` 和 `v` 一致（小数点后忽略浮点误差），说明你的"换基器"和 Day 1 的"线性组合"是一对**互逆的好搭档**。测试文件里 `test_roundtrip` 干的就是这件事——所以它其实同时考核了你前两天写的东西。

## 📌 AI 联系：解方程，就是 AI 里"求配方"的原型

`坐标 → 配方` 这一步，等于回答"给一个已观测到的结果，它的成分是什么"。在 AI 里，这类"从结果反推成分/参数"的任务无处不在：拟合一条线要找斜率截距、训练一个网络要找权重……它们的统一形状都是"解方程（或近似解方程）"。你今天写的这个 $2\times 2$ 求解器，是这一整族工具里最小、最透亮的一个。
