# Day 6：AI 联系——embedding 的坐标是"语义配方"

> 本章你将：
> - 用本周的"坐标 = 尺子 + 系数"视角，看透 **embedding** 到底是什么；
> - 理解"词的每一维"其实是**一个语义刻度的读数**；
> - 明白"词向量 = 各语义刻度的**配方**"，即一次线性组合；
> - 第一次看到那句名言级的例子：**$\text{国王} - \text{男人} + \text{女人} \approx \text{女王}$**；

---

## 6.1 从"箭头"到"词"：都是坐标

一周前你还是把向量当"地图上的箭头"，今天要往前跨一大步：**向量也能代表一个"词"的意思。**

怎么做？回忆 Week 1 Day 2 你已经见过的一招：**给每个词找一组坐标**。像给颜色编 $(\text{红}, \text{绿}, \text{蓝})$ 三个数一样，给每个词也编一串数。这串数就叫这个词的 **embedding（词向量 / 嵌入向量）**，少则几十维，多则几百上千维。

现在用本周新学的语言重新读一遍这串数：

> 一个词的 embedding 向量 = **这个词在一套"语义尺子"下的坐标。**

换句话说，每个词都像 Day 4 那支红箭头 $v$，被放在某个高维空间里，读出了一组数。**词，就是语义空间里的一支箭头。**

---

## 6.2 每一维，是一个"语义刻度"

以颜色为例（三维、最好懂）：一个颜色 = $(\text{红}, \text{绿}, \text{蓝})$ 三个读数，每一维是一根刻着"这一种颜色成分加了多少"的尺子。

embedding 是同一个玩法，只是尺寸换成"语义"：

| 维度 | 这根"语义尺子"量的是什么 |
|---|---|
| 第 1 维 | "动物性 / 非动物性"上有多少 |
| 第 2 维 | "贵气 / 亲切"上有多少 |
| 第 3 维 | "温暖 / 冰冷"上有多少 |
| … | … |

（当然这只是打比方——真实的 embedding 维度不像"红绿蓝"那样能一眼命名，而是几十上百个人类难以描述的"抽象语义方向"，但**结构和颜色三维是完全一样的**。）

所以"每个词的向量"= "它在所有语义刻度上的读数清单"。这不是玄学，就是 Day 3 说的**把东西放到坐标系里读数**。

> 📌 **划重点：embedding 的每一维 = 一根语义刻度轴；词向量 = 这个词在各语义刻度轴上的读数（坐标）。**

---

## 6.3 词 = 各语义刻度的"配方"（线性组合视角）

Day 3 还有半句话没在 AI 上落地：**坐标是系数的读法，背后是一次线性组合。**

回顾标准基下的箭头：$(4, 3) = 4\cdot e_1 + 3\cdot e_2$，读作"4 份 $e_1$、3 份 $e_2$ 调出来"。

把 $e_1$、$e_2$ 换成**语义基向量**（每根轴代表一种"纯粹语义方向"，比如"纯动物性"、"纯温暖"），那么：

> 一个词的 embedding = $c_1\cdot(\text{语义轴}_1) + c_2\cdot(\text{语义轴}_2) + \dots + c_n\cdot(\text{语义轴}_n)$

翻译成人话：**一个词的意思，是"各种语义成分"按一定比例调制出来的一碗"配方"。** 系数 $(c_1, c_2, \dots)$ 就是这个词的坐标，也是这个配方的比例。

这样，"关近义词"这件事就有了干净的解释：两个词向量相似（指向接近），意思是它俩的**语义配方比例接近**——就像"深红"和"紫红"在 $(\text{红}, \text{绿}, \text{蓝})$ 里读数接近，是因为它们都不是纯色、且红的比例都高。

> 💡 **你可能会问：语义轴那么抽象，这模型靠谱吗？** 靠谱与否不靠"人类能不能给每根轴起名"，而靠这些坐标**能不能稳定地反映语义关系**——下面的例子会给你看一件事：用它做加减法，真的会冒出合理的词。

---

## 6.4 向量加减 = 语义的加减：国王的著名配方

把"配方"想成可以**调**的东西，就会得到一个看起来很邪门、却极其有名的结果：

> $\text{国王} - \text{男人} + \text{女人} \approx \text{女王}$

这在 2013 年 word2vec 论文里首次公之于众，震惊了一大片人。它用本周的视角其实很好懂：

- 一个词的向量是它的**语义配方**；
- 向量相减 = **把两个配方的差异求出来**；
- 向量相加 = **往配方里加东西**。

于是"$\text{国王} - \text{男人}$"求的是"国王这个配方里，去掉'男人'这部分之后剩下的东西"——剩下的未必是具体成分名，而是某个**抽象方向**，大致可以理解为"王室、君权、高贵"这类"王族属性"。

接着再" + 女人"，等于把这个"王族属性"的方向，**加进"女人"的配方**里。结果顺理成章地落到了——"女王"。

$$
\begin{aligned}
\text{国王} - \text{男人} &\approx \text{王族属性（一个抽象的语义方向）} \\\\
\text{女王} &\approx \text{女人} + \text{王族属性}
\end{aligned}
$$

把两式合起来，就是那句名言。**它之所以成立，正是因为"词→向量"这件事把这些词放进了同一个坐标系，让"坐标加减"对应了"语义加减"。**

> ⚠️ **易踩坑：别把"男人/女人"理解成纯粹的一根轴。** "$\text{国王} - \text{男人} + \text{女人}$"严格说是在高维空间里走"减法再加法"的两步，不是简单地"性别的轴上调个号"。心智图景用"配方 + 一道方向"就好，不必精确到某一维。

> 📌 **划重点：embedding 把所有词放进同一个语义坐标系后，"向量加减"就成了"语义加减"。** 这是本节、也是后世无数 NLP 直觉的第一块基石。

## 📌 AI 联系：本周直觉，在 LLM 里的落点

把这一整周串成一条线，看它如何直达你关心的 LLM 底层：

1. **线性组合**（Day 1）= 把向量按系数混起来——后面神经网络一层 $Wx + b$、attention 的加权求和，都是它；
2. **张成 / 基**（Day 2、3）= 一组"尺子"张出一个空间；embedding 空间就是被语义尺子张出来的高维空间；
3. **换基 / 配方求解**（Day 4、5）= 从坐标反推成分；这是"解线性系统"的雏形，Week 7 的 $Ax = b$ 是它的 n 元版；
4. **词向量 = 语义配方**（Day 6 本章）= 让"相似度""语义运算"都有了可计算的形状。

但这套"坐标观"还有一个**另一半**还没讲：向量可以被**变换**——把整片空间的点一起拉、转、压。而"对整个空间做一次变换"这个动作，正是**矩阵**。

本章是 AI 联系章，重点是"用本周语言把一件事讲清楚"，动的是脑和嘴，不是新代码：

1. 翻出你 Day 5 写的 `coordinates_in_basis`，用"换基器"的视角，向自己复述一遍"为什么换一套语义尺子，同一个词的 embedding 会变，但意思还在"。
2. 用一段话写给未来的你：解释 $\text{国王} - \text{男人} + \text{女人} \approx \text{女王}$ 为什么"不神奇"，只是坐标加减 + 换配方。
3. （选做）如果你已经装了 numpy，跑一下下面的玩具，感受"词当向量、加减当配方"：

```bash
python -c "
import numpy as np
# 玩具语义轴：(男/女, 王族/平民) 两根刻度
king   = np.array([9, 10])
man    = np.array([9,  1])
woman  = np.array([1,  1])
queen  = king - man + woman
print('国王-男人+女人 =', queen, '（女王 =', np.array([1, 10]), '）')
"
```

（这里"王族"的读数 toy 化为 10 vs 1，只是为了让你看见"减法抠掉男人、加法补进女人、王族成分原样保留"。真实 embedding 是几十上百维，但结构一样。）
