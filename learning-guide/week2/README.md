## 🗺️ 一张图看懂本周

![张成：用两支不共线的箭头铺满整个平面](../../figures/out/w2d2_span.png)

本周要攻克的，就是图上这张**斜网格**：

- 蓝色 b1、绿色 b2 是两支**不共线**的箭头——它们组成了**一套尺子（基）**；
- 网格上每一个点，都是"沿 b1 走几格、沿 b2 走几格"走到的地方，也就是一个**线性组合**；
- 同一个点，用不同的尺子去量，读数不同——**坐标的本质，是"拿着哪把尺子量出来的数"**。

## ✅ 学完你会得到什么

- 两个你自己写的函数模块：`matrixlab/combo.py`（线性组合、张成）和 `matrixlab/solve2.py`（换基器），配合 `IMPL=matrixlab pytest tests -k w2` 全绿。
- 一句话讲清"线性组合""张成""基""坐标"四个词，还能用"尺子 vs 读数"的类比给没学过的人讲明白。
- 会用**加减消元法**解任意二元一次方程组，并清楚"无解 / 无穷多解"各对应尺子的什么病态。
- 能把 **embedding** 和本周直觉接通：词是语义空间里的箭头，词向量是它在语义尺子下的读数，"国王 - 男人 + 女人 ≈ 女王"不再神秘。
- 一张通往 Week 3 的门票：学到这里，你已经有资格问"那能不能让整个空间**动起来**？"——那就是矩阵。
