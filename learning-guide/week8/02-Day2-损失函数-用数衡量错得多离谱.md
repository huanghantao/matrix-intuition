# Day 2：损失函数——用数衡量"错得多离谱"

> 本章你将：
> 1. 明白"学习"得先有个**打分标准**：网络错得越多，分数越高——这个分数就是**损失函数**；
> 2. 亲手实现均方误差 `mse_loss`，并看清它就是 Week 7 Day 6 最小二乘换了个名字；
> 3. 建立本周最关键的视角：**损失是参数的函数**，参数一变损失就变——这正是 Day 1"下山"要下的那座山。

---

## 2.1 学会之前，先得会说"错得多离谱"

昨天我们学会了一件事：想知道"往哪走能变好"，先得量出"有多好 / 有多差"。可是"网络好不好"这种话太虚了，得要一个**数字**。

回想你 8 周前第一次认识"训练"时听到的那句承诺（Week 1 第 0 章）：神经网络"能学习"。但机器怎么知道自己在进步呢？答案是：**每个网络心里都装着一把尺子，能量出"我现在错得多离谱"**。这把尺子测量出的那个数，就叫**损失（loss）**。训练的全部目标，就是让这个数**一路变小**。

> 📌 划重点：损失函数 = 给"预测错得有多离谱"打分的规则。输入是"预测"和"真答案"，输出是**一个数**，越大越糟、越小越好。

---

## 2.2 一条你已经见过的尺子：平方误差

其实这把尺子你在 Week 7 Day 6 已经握在手里了——那时它叫"最小二乘"：拟合一条线，把每个数据点"预测值-实际值"的差的**平方**加起来，越小说明线越靠得住。

```
单个样本的误差 = 预测 - 实际
单个样本的平方误差 = (预测 - 实际)²
```

为什么要点名"平方"而不是直接加误差？因为误差有正有负——预测大了是正、小了是负，直接加会**互相抵消**（两个都错得离谱的样本，一个 +5 一个 -5，加完是 0，系统还误以为"完美"）。平方把负号抹掉（负数的平方也是正数），让"每个错"都只能往大数累加，谁也赖不掉。这是 Week 7 就讲过的老把戏，现在换个名字继续用它。

---

## 2.3 均方误差（MSE）：平方之后，再求平均

平方和有个小毛病：**样本越多，数天然越大**——不是错得更多，只是"家口大了"。我们想让损失"错得越狠分越高"，而不是"样本越多分越高"，所以要**除以样本个数 N**，求个平均。这把尺子的全名是**均方误差（Mean Squared Error）**，缩写 MSE：

```
MSE = (1/N) × Σ (预测 - 实际)²
     = 所有样本的平方误差，加起来，再除以样本数
```

Σ 就是 Week 7 反复用的"求和"符号（把后面那个式子挨个样本算一遍再加起来），`1/N` 就是"平均"。这一加一平均，损失就从"总误差"变成了"平均每个样本错多少"。

看一个手算例子（正好是测试 `test_mse_loss` 的点）：

```
预测: [1.0, 0.0]
实际: [0.0, 0.0]

样本 0 的误差 = 1.0 - 0.0 = 1.0，平方 = 1.0² = 1.0
样本 1 的误差 = 0.0 - 0.0 = 0.0，平方 = 0.0² = 0.0

MSE = (1.0 + 0.0) / 2 = 0.5
```

两个样本，一个错得离谱（预测 1 实际 0）、一个完美——平均下来损失 0.5。全对的时候 MSE 是 0，预测离实际越远，MSE 涨得越快（平方意味着"错 2 分扣 4 分"，误差会被放大，逼着网络不敢大错）。

## 2.4 实现 mse_loss

打开战场 `matrixlab/nn.py`，我们要实现今天的第一段代码：

```python
def mse_loss(y_pred: np.ndarray, y: np.ndarray) -> float:
    """均方误差：(1/N) Σ (预测 - 目标)²。"""
    raise NotImplementedError("TODO: Week 8 Day 2 —— 均方误差")
```

这里第一次正式用 numpy 的广播写法，一行就能搞定，逐块解释：

- `y_pred - y`：两列数**对应相减**，一次把 N 个样本的误差全算出来。numpy 的 `-` 对两个形状相同的数组是"逐元素"运算（不是列表那种连不上的概念）。
- `(y_pred - y) ** 2`：逐元素**平方**（`**` 是 Python 的幂运算符，`2` 就是平方）。
- `np.mean(...)`：对整张表**求平均**——内部先求和再除以元素个数，正好是 `(1/N)×Σ`。
- 最后套 `float(...)` 把 numpy 的标量转成普通 Python 浮点，让返回值类型干净（参考答案里就加了这个）。

于是整行是：

```python
return float(np.mean((y_pred - y) ** 2))
```

分两步看就是：先 `squared = (y_pred - y) ** 2` 得到每个样本的平方误差，再 `float(np.mean(squared))` 求平均。numpy 让"整张表一起算"变得像写公式一样自然。

## 2.5 把尺子接进网络：loss 方法

有了 `mse_loss`，网络就能"自评"了。在 `matrixlab/nn.py` 的 `TwoLayerNet` 类里，有个方法待实现：

```python
def loss(self, X: np.ndarray, y: np.ndarray) -> float:
    """先跑前向，再算均方误差。"""
    raise NotImplementedError("TODO: Week 8 Day 2 —— 损失")
```

它的思路一句话：**先让网络算一遍预测（前向，Day 3 才实现），再拿预测和真答案去算 MSE。**

```python
def loss(self, X, y):
    y_pred = self.forward(X)          # 网络算出的预测（明天实现 forward）
    return mse_loss(y_pred, y)        # 预测 vs 实际 → 一个数
```

等一下——`forward` 不是明天才写吗？没错。`loss` 本身可以先照着写（它逻辑就这两行），但只要 `forward` 还是 `raise NotImplementedError`，一跑就会炸。所以**今天的验收先只跑 `mse_loss` 的测试**，`loss` 要等 Day 3 写完 `forward` 才能真正转起来。这种"今天的函数要调用明天的函数"的分工，正是神经网络"先整骨架、后逐个填肉"的自然顺序。

> 💡 **你可能会问：`loss` 和 `mse_loss` 不是重复了吗？干嘛要两层？**
>
> 分工不同。`mse_loss` 是**纯数学尺子**：给它两串数（预测、真值），还你一个分，它不知道"网络"为何物，谁都能用。`loss` 是**网络的方法**：它知道"我的预测得先 forward 一次"，所以它负责"先算预测、再请 `mse_loss` 打分"。一层管数学、一层管流程，清清楚楚。

## 2.6 最关键的一步：损失是参数的函数

这一节不长，却是整个"学习"的地基，务必停一下想明白。

写代码时，`X`（输入）和 `y`（真答案）是**固定不动**的——训练数据就长那样。会变的是网络里的参数：`W1、b1、W2、b2`（Day 3 你会认识它们）。参数一换，网络的预测就换，预测一换，损失就换。

所以，把输入和答案"焊死"之后，**损失就只依赖参数**：

```
损失 = 关于 (W1, b1, W2, b2) 的函数
```

举个最小的例子体会一下"参数一变损失就变"：假想一个只含一个参数 w 的网络，某条数据上它的损失是 `L(w) = (w - 0.7)²`。那么：

- w = 0.7 时，L = 0（预测正好命中，零损失）；
- w = 0.1 时，L = (0.1-0.7)² = 0.36（差得远，损失大）。

这就是你昨天学"下山"时心里朦胧的那座山，今天它有了实体：**每个参数组合对应山上一个高度（损失），训练就是从某个高处滚到谷底（w=0.7 那种让损失最小的参数）。**

> 📌 划重点：**把训练数据固定住，损失就成了"参数的函数"。** "训练网络"和"下山"是同一件事的两种说法：损失是山的海拔，参数是山上的位置，训练就是往谷底走。

## 2.7 损失曲线长什么样（先把话说在前头）

Day 6 你会亲眼看到一张"损失曲线"图（`w8d6_decision_boundary.png` 的右半边），横轴是训练的步数、纵轴是损失，一条橙色线**一路往下掉**。今天先把它要长成的样子埋个伏笔：

- 训练一开始，参数是随机瞎猜的，损失高（山上高处的海拔；XOR 上未训练的初始损失约 2.3）；
- 每走一步（Day 5 的梯度下降），损失就矮一点；第一轮更新后就从 2.3 掉到约 0.36；
- 走几千步，损失跌到 0.05 以下——几乎贴地了，网络"学会了"。

这条曲线就是你"下山之旅"的行车记录仪。它的形状由今天这把尺子（MSE）和昨天那个直觉（反着梯度走）共同决定。别急，几步之后它就会出现在你的屏幕上。

> 📌 **AI 联系：** 现实里训练 LLM，损失曲线是工程师最常盯的一张图——它一抖一拐，团队就知道"学习率调坏了""数据没喂对"。而你今天写的 `mse_loss`（平方 + 平均）和 GPT 那套"交叉熵损失"虽然长得不一样，**分工完全相同**：都是一把"错越多分越高、越准分越低"的尺子。会用一把尺子，所有的尺子你都能看懂门道。

## 2.8 本章小结

- ✅ 损失函数 = 给"错得多离谱"打分的规则：越大越糟、越小越好。
- ✅ MSE = (1/N)Σ(预测-实际)²：先平方（抹负号、放大误差）再平均（跟样本数解耦）。
- ✅ `loss` = 先 `forward` 拿预测，再喂 `mse_loss`；数学和流程分层。
- ✅ 最关键的视角：**固定数据后，损失只是参数的函数**——它是"下山"要下的那座山。
