# 🚀 Week 8：神经网络 = 一连串变换——大结业：从零训练一个小网络

> **适合谁：** 已经走完前 7 周的你——手里有向量、线性组合、矩阵变换、坐标系、点积、attention、最小二乘这七件工具，但还差最后一块拼图：**神经网络是怎么"自己变聪明"的。**
>
> **本周定位：** 把 7 周攒下的所有直觉，拧成一个会自己学习的程序。你不再"手算一个变换"，而是**让计算机自己找到那个正确的变换**——从零写出前向传播、反向传播、梯度下降，最后训练出一个两层网络，学会单层搞不定的 XOR。
>
> **承诺：** 不碰任何深度学习框架，只用 numpy 和初中数学。"导数"这个词你从没学过也没关系，本周会从"直线的斜率"现教，一路教到"梯度下降一步该怎么走"。

## 🗺️ 一张图看懂本周要造什么

```
   输入 x ──► [ z₁ = W₁x + b₁ ] ──► [ h = ReLU(z₁) ] ──► [ z₂ = W₂h + b₂ ] ──► 预测 ŷ
                  (Week 3 变换)          (开关：负的抹掉)        (再变换+平移)
                                                                              │
   参数 W₁,b₁,W₂,b₂ ◄─── 沿"梯度"反方向挪一小步 ◄─── 损失 L = 平均(预测 - 目标)²
                  (Day 5 梯度下降)                    (Day 4 反向传播)   (Day 2 损失函数)
```

左边往前跑叫**前向传播**（Day 3），算出错得多离谱叫**损失**（Day 2），把"错"一层层传回每个参数叫**反向传播**（Day 4），每个参数朝错的相反方向挪一步叫**梯度下降**（Day 5）。重复几千遍，网络就学会了（Day 6）。

这条流水线上没有一样是全新的东西——**每次 `Wx+b` 就是一次 Week 3 的矩阵变换**，损失里的平方就是 Week 7 学的最小二乘。本周唯一的新概念是"变化率"（导数，Day 1），而它只是初中"直线斜率"的推广。

## ✅ 学完你会得到什么

- 一个**你自己从零写、自己训练**的两层神经网络：用手写的前向/反向/梯度下降，在 XOR 上把损失从初始的约 2.3 一路压到接近 0（远小于 0.05），四个点全部分对。
- 对"神经网络为什么能学习"**透彻、可脱稿讲解**的理解：学习 = 给"损失"找一个让损失变小的方向，然后一步一步滑过去。
- 一把神器：**数值梯度**——以后无论拿到多复杂的网络、多花哨的算子，你都能用它抽查"反向传播写没写对"。
- 一张通往**真正的深度学习框架**的门票：本周 40 行 numpy 代码，就是 PyTorch 那 4 行代码背后的全部秘密。
