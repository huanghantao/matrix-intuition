> 本章你将：

> 3. 实现 `TwoLayerNet.backward`，并逐行听懂每条公式在算什么；

## 4.1 昨天的问题：想让损失变小，得先知道"每个参数该往哪调"

Day 2 得出结论：训练 = 下山，损失是山的海拔，参数是山上的位置。Day 1 的结论：下山该走的反方向是**梯度**——"损失关于每个参数的变化率"。

现在的问题聚焦成一个：**损失 L 关于 W1、b1、W2、b2 每一个参数的变化率，怎么算？**

一个参数还好办，用 Day 1 的数值梯度"捅一捅"就行。但网络有一堆参数（哪怕今天这个迷你网络，也有 W1 的 2×2、W2 的 2×1 等 10 个数），逐个"捅"要前向算几十遍，又慢又笨。于是有了今天的主角——**反向传播（backprop）**：不逐个捅，而是**顺着流水线，从损失这头逆着走回去，把变化率一层层传回每个参数**。

它的数学内核只有一个，叫**链式法则**。

---

## 4.2 链式法则 = 变化的传导：接力棒与多米诺

先给一个生活化的画面。想象四个工人排成一条流水线，原料从 A 流到 B、再到 C、最后到 D 出成品，损失就是"成品有多不合格"：

```
A(参数 W1,b1) ──► B(Z1) ──► C(H) ──► D(输出) ──► 损失 L
```

现在问：**最左端的 A 稍微动一下，最右端的 L 会变多少？** 这个变化不是一下子发生的，而是**一段段接力**传导过去的：

- A 动一点 → B 跟着变一点（这一段的"传导比例"记为 B 对 A 的敏感度）；
- B 变 → C 变一点（C 对 B 的敏感度）；
- C 变 → D 变（D 对 C 的敏感度）；
- D 变 → L 变（L 对 D 的敏感度）。

直觉告诉你：**总效果 = 每一段"传导比例"连乘起来**。A 动 1，B 动多少、再传到 C 又放大多少、再到 D、再到 L……一站一站的倍数乘一块，就是"A 动 1 时 L 到底变多少"。

这就像**多米诺骨牌**：第一块倒的速度，决定了第二块、第三块……最后一块倒得有多猛，总效果是**每一块的传导系数连乘**。也像**接力棒**：四个人一棒棒传，总时间 = 每棒耗时的影响累乘。

> 📌 划重点：**链式法则就是"变化的传导按段连乘"。** 想知道链条最左端对最右端的影响，就把中间每一段的"变化率"乘起来。

数学上一句话（本课不要求你写这个形式，只懂意思）：`dL/dA = (dL/dD)·(dD/dC)·(dC/dB)·(dB/dA)`。

---

## 4.3 反向传播 = 从右往左，一段段把"乘积"算出来

链式法则给方向了，但还有一个更聪明的观察：链条里每段"敏感度"会被**很多层复用**。与其每个参数都从左往右重新连乘一遍，不如**从右往左逐层算**，把已经算好的乘积**缓存**下来传回去——这就是"反向"二字的来历，也正是 `backward` 的骨架。

回忆 Day 3 存的三个中间量，就是为这一刻准备的（`self.out`、`self.H`、`self.Z1`）。反向时：

1. 从损失出发，先算 `dout` = L 对输出的变化率；
2. 拿它穿过第三站 `z₂ = W₂h + b₂`，得到 `dW2`、`db2`，以及要传给上一站的 `dH`；
3. 再穿过 ReLU（开关：正放行、负归零）得到 `dZ1`；
4. 最后穿过第一站得到 `dW1`、`db1`。

一步不落，和 Day 3 的 `w8d4_chain.png` 里那些**红色箭头**一一对应——图里那句话"各层导数连乘（链式法则）"，说的就是这件事。

## 4.4 一个 2 神经元玩具：完整手算一遍

光讲道理不够，我们拿一个**最小的网络**，把上面四步亲手算一遍，每个数都能跟得上。构造如下（这是个"单样本"玩具，N=1，为的是数字干净；多样本只是把每行加起来而已）：

**参数与数据：**

```
X = [[2, 1]]               # 1 个样本，2 维
y = [[0]]                  # 正确答案是 0

W1 = [[ 1, -1],            # 2×2：把 2 维变 2 维
      [ 0,  1]]
b1 = [0, 0]
W2 = [[ 3],                # 2×1：把 2 维收成 1 维
      [-2]]
b2 = [0]
```

**第一步，前向（就用 Day 3 的公式）：**

```
Z1 = X @ W1 + b1
   = [2, 1] · 第一列 + [2, 1] · 第二列
   = [2·1 + 1·0,   2·(-1) + 1·1]
   = [2, -1]

H = relu(Z1) = [max(0,2), max(0,-1)] = [2, 0]     ← 第二个神经元被"关"了！

out = H @ W2 + b2 = 2·3 + 0·(-2) = 6
```

网络输出 6，正确答案 0，错得离谱——损失该很大。现在**反向**，看每个参数该往哪调。

**第二步，损失对输出的变化率 dout。** 损失是 MSE：L = (out - y)²（N=1 时平均那个 1/N 就是 1/1，而平方前那个 2 来自求导，下面细说）。"L 对 out 的变化率" = 2·(out - y)：

```
dout = 2·(out - y) / N = 2·(6 - 0) / 1 = 12
```

（那 2 从哪来？`(out-y)²` 是平方函数，数学上"平方的导数是 2×自身"——这和 `x²` 的变化率是 `2x` 是一回事，Day 1 那根斜坡函数 `(x-2)²` 的斜率 2(x-2) 里也有个 2。你只需记住公式，不必当堂推。)

**第三步，穿过第三站 `z₂ = W₂h + b₂`。** 这一站是"对 H 各元素加权求和（W2 当权重）再加 b2"。out 对每个 h 的变化率恰好就是对应的权重 W2：

```
dH  = dout @ W2.T = 12 · [3, -2] = [36, -24]
dW2 = H.T @ dout  = [[2],[0]] · 12 = [[24],[0]]
db2 = dout 的和    = 12
```

读一下含义，非常直观：

- `dW2 = [[24],[0]]`：W2 的第一行（挂着活跃神经元 h1=2 的那个权重）该调 24；**第二行是 0**——因为它连着的 h2 已经被 ReLU 关成 0 了，动它没任何影响。
- `dH = [36, -24]`：告诉上一站"h1 该往 +36 方向推、h2 该往 -24 方向推"。

**第四步，穿过 ReLU（开关！）。** dH 说的是"h 该怎么变"，但 h 本身是 z1 过 ReLU 来的。ReLU 的传导规则一句话：**z1 为正 → 原样放行（乘 1）；z1 为负 → 关门（乘 0）**。所以用 `(Z1 > 0)` 当开关逐元素乘：

```
dZ1 = dH * (Z1 > 0) = [36, -24] * [真, 假] = [36, 0]
```

dH 第二项 -24 直接被"关掉"了——因为 h2 本来就是由负数 z1=-1 压成的 0，往回传时这里没有"活路"。**这就是"ReLU 的导数 = 开关"**：正放行、负归零，和 ReLU 本身一脉相承。

**第五步，穿过第一站 `z₁ = W₁x + b₁`。** 最后一站和第三站同构：

```
dW1 = X.T @ dZ1 = [[2],[1]] · [36, 0] = [[72, 0],
                                          [36, 0]]
db1 = dZ1 的和   = [36, 0]
```

同样漂亮：第一列（连着 z1_1=2 那个活跃神经元）有梯度，第二列全是 0（z1_2=-1 被关了）。

**汇总这张手算梯度表：**

| 参数 | 梯度 | 含义 |
|---|---|---|
| dW2 | [[24],[0]] | 活跃的那条权重该 +24，被关的那条不动 |
| db2 | [12] | 输出偏置该 +12 |
| dW1 | [[72,0],[36,0]] | 活跃神经元相关的该调，被关的整列为 0 |
| db1 | [36,0] | 同上 |

你不需要每次都算得这么细——但**这张表里藏着的就是"学习"的全部秘密**：每个参数都拿到了"该往哪个方向、改多少"的明确指令。之后 Day 5 只要照着 `参数 -= 学习率 × 梯度` 各挪一小步，损失就会下降。

> 💡 **你可能会问：那些 `X.T @ dZ1`、`H.T @ dout` 的转置 `.T` 是干嘛的？**
>
> 是为了让矩阵尺寸对得上。`.T` 是 numpy 的"转置"（把行变列、列变行，Week 3 手写过 `transpose`）。比如 `dout @ W2.T`：dout 是 (1×1)，W2 是 (2×1)，直接乘尺寸对不上，转成 W2.T(1×2) 就能乘出 (1×2) 的 dH。**每处转置的唯一目的，都是凑成"前列数=后行数"的形状规则**（Day 3 那条）。放慢看形状，比背公式有用得多。

## 4.5 把四步写进 backward

对照上面手算，`backward` 的代码就是逐条公式（先 forward 一次把 `out/H/Z1` 备好，再反向）：

```python
def backward(self, X: np.ndarray, y: np.ndarray):
    N = X.shape[0]                          # 样本数（手算玩具里 N=1）
    dout = 2.0 * (self.out - y) / N         # 第二步：损失对输出的变化率
    dW2 = self.H.T @ dout                   # 第三步：第三站的权重梯度
    db2 = dout.sum(axis=0)                  # 第三站的偏置梯度
    dH = dout @ self.W2.T                   # 要传给上一站的信号
    dZ1 = dH * (self.Z1 > 0)                # 第四步：ReLU 开关
    dW1 = X.T @ dZ1                         # 第五步：第一站的权重梯度
    db1 = dZ1.sum(axis=0)                   # 第一站的偏置梯度
    return {"W1": dW1, "b1": db1, "W2": dW2, "b2": db2}
```

运行时表里多了一个新面孔 `sum(axis=0)` 要解释一句：偏置 `b` 是"加到每一行上的那个东西"，它对所有样本共同作用，所以它的梯度要把 N 个样本的贡献**沿第 0 维（样本维）加总**。`dout.sum(axis=0)` 就是"竖着把每一列（每个输出神经元）在 N 个样本上的梯度加起来"，得到形状和 `b` 一致的一列数。(这里 N=4 时更明显：b2 长度 1，dout 是 4×1，`sum(axis=0)` 把它压回 1×1。)

把 `backward` 的每一行，和 4.4 的"第 N 步"对上，你会发现公式一点都不神秘，就是链式法则一段段连乘 + 用 ReLU 开关咔掉被关的神经元。

## 4.6 用数值梯度这只尺子抽查 backward

公式这么多，写错一个标点结果就全错，怎么知道对不对？——Day 1 造的那把"验算尺"此刻派上用场了。

思路：backward 算出来的 `dW2[0,0]`，理论上 = "单独把 W2[0,0] 捅一捅算出来的数值梯度"。两者该一致。这就是测试 `test_gradient_check_output_layer` 干的事：

```python
# 单独扰动 W2[0,0]，用中心差分算 dL/dW2[0,0]
eps = 1e-6
old = net.W2[0, 0]
def loss_with(value):
    net.W2[0, 0] = value
    L = net.loss(X, y)
    net.W2[0, 0] = old
    return L
numeric = (loss_with(old + eps) - loss_with(old - eps)) / (2 * eps)
assert grads["W2"][0, 0] == approx(numeric, abs=1e-6)
```

你看——`loss_with` 就是"把某个参数改一改、再算一遍损失"。这正是 Day 1 的中心差分 `(f(x+ε)-f(x-ε))/(2ε)`，只不过被"捅"的 `x` 从标量换成了 `W2[0,0]` 这个具体参数。**backward 用 6 行公式一次性算出的梯度，必须和"逐个捅"得到的数值梯度对得上，对得上就说明公式没写错。** 测试 `test_gradient_check_hidden_layer` 如法炮制，抽查的是更深处、更难算对的 `W1[1,0]`。

跑起来：

```bash
pytest tests -k nn -q
```

此时该看到 `test_relu`、`test_mse_loss`、`test_forward_shapes`、`test_gradient_check_output_layer`、`test_gradient_check_hidden_layer` 全都绿。（`test_training_reduces_loss`、`test_xor_learned` 还需要 Day 5 的 `sgd_step`/`train`，仍红，正常。）

> 📌 **AI 联系：** 现实里 PyTorch 这类框架，你**从不需要手写反向传播**——`loss.backward()` 一句就自动算完，靠的是一个叫"自动微分"的引擎，本质就是链式法则的机器版。但框架再怎么自动化，**check 梯度的思路和你今天一模一样**：工程师仍会不定期拿数值梯度抽查自动微分有没有 bug。你今天学会的"数值梯度验算尺"，是 AI 圈永不过时的基本盘。

3. **思考**：`dZ1 = dH * (Z1 > 0)` 里，`(Z1 > 0)` 是个**布尔数组**（True/False）。numpy 里 True 当 1、False 当 0 参与乘法——说清楚这行"开关"是怎么起作用的。

## 参考答案

1. 见 `reference/nn.py` 的 `backward`，就是 4.5 六行。**卡住 20 分钟再看**，重点核对 `H.T @ dout`、`dout @ W2.T`、`X.T @ dZ1` 三处转置的方向。
2. 换 W2 第二行后：out 仍是 6（因为 h2=0，第二行不参与），dout=12 不变；dH=[36,-24] 形式不变但 dW2 第二行仍为 0——**h2 被关，第二行挂多少都没梯度**。这正说明 ReLU 开关"断路"了那一路。
3. `Z1 > 0` 逐元素判断，正→True(乘 1)、非正→False(乘 0)，于是 `dH * (Z1>0)` 把被关神经元对应的梯度清零。

## 4.7 本章小结

- ✅ 链式法则 = 变化的传导按段连乘（接力棒 / 多米诺）。
- ✅ 反向传播 = 从损失往左，逐层把"乘积"算出来并缓存复用，对应 `w8d4_chain.png` 的红箭头。
- ✅ 手算 2 神经元玩具：`dout=12 → dW2=[[24],[0]], db2=[12] → dH=[36,-24] → dZ1=[36,0] → dW1=[[72,0],[36,0]], db1=[36,0]`。
- ✅ ReLU 的导数 = 开关：`(Z1 > 0)` 正放行、负归零，把被关神经元的梯度咔掉。
- ✅ 数值梯度 = 验算尺，两条 `test_gradient_check_*` 就是用它抽查 backward。
